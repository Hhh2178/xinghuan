# 长期记忆

这里用于承接跨会话仍成立的项目记忆。

## 这一层放什么

- 当前长期有效的阶段判断
- 当前部署和运行环境结论
- 长期边界与风险
- 跨多个任务会重复引用的决策

## Phase 1 现状

- 兼容主入口仍是 `MEMORY.md`
- 本目录已建立为后续主题拆分的目标位置
- 当前已拆分主题：
  - `current-state.md`
  - `product-and-scope.md`
  - `architecture-decisions.md`
  - `deployment-state.md`
  - `runninghub-memory.md`
  - `provider-memory.md`
  - `recent-release-index.md`
  - `worktree-and-runtime-history.md`
  - `runtime-artifacts-and-archive-rules.md`
  - `project-origin-and-core-requirements.md`
  - `decision-history.md`
  - `base-evaluation-criteria.md`
  - `server-and-stage-history.md`

## 现在怎么用

- 快速恢复长期上下文：先看 `MEMORY.md`
- 要新增长期记忆时：优先考虑写入本目录，而不是继续把所有内容堆进单个大文件
