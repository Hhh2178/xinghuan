# 运行产物目录说明

本文件用于说明当前 worktree 中哪些目录属于运行产物、验收输出或本机辅助状态，而不是正式源码。

## 目录分类

### 正式源码与长期文档

- `apps/`
- `packages/`
- `scripts/`
- `config/`
- `docs/`
- `ops/`
- `development/`
- `research/`
- `AGENTS.md`
- `MEMORY.md`
- `DEVLOG.md`

### 运行产物与本机辅助目录

- `output/`
  - 本机输出素材、临时导出和验收生成产物。
- `releases/`
  - 本地打包或待上传的 release 产物目录。
- `dist-release/`
  - 当前构建后的分发产物。
- `logs/`
  - 本机运行日志和验收日志。
- `.tmp/`
  - 临时脚本、调试中转或一次性过程文件。
- `.codex-temp/`
  - Codex 本地辅助过程目录。
- `.codegraph/`
  - 仓库分析缓存。
- `.playwright-cli/`
  - 浏览器验收辅助状态。

## 使用规则

- 这些目录不应被当作正式需求文档或源码结构的一部分。
- 这些目录中的文件可以作为本机排查证据保留，但不应在方案文档里被描述成“长期主结构”。
- 若其中内容需要长期保留，优先把结论沉淀到 `docs/`、`ops/`、`DEVLOG.md` 或 `MEMORY.md`，不要把原始运行产物直接当知识库。
- 若确认某个运行产物单文件已无价值，可以后续按单个明确路径进行清理；禁止批量删除。

## 当前整理策略

- 当前先做“结构归位”和“入口清晰化”，不直接大规模清空运行产物目录。
- 后续若要继续瘦身，应优先：
  - 先确认哪些日志和 release 包仍需要作为验收证据
  - 再逐个文件清理，而不是直接清目录
  - 对仍有保留价值但不应占主路径的内容，优先移动到专门归档位置
