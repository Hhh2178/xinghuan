# 文档治理

这里存放无限画布 2.0 的协作规则、入口顺序、归档政策和仓库导航方法。

## 这一层放什么

- 协作流程
- 文档分类规则
- 阅读顺序
- CodeGraph 与 `rg` 的使用边界
- 归档与清理规则

## 这一层不放什么

- 业务系统的协议细节
- 逐日推进记录
- 单次发布与验收证据

## 推荐阅读顺序

1. `collaboration-and-workflow.md`
2. `codegraph-and-repo-navigation.md`
3. `archive-policy.md`
4. `templates/README.md`
