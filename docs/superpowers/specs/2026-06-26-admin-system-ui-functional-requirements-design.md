# 后台系统 UI 功能与需求完整设计文件

**日期：** 2026-06-26  
**范围：** 无限画布 2.0 Admin 后台新系统 UI 的功能区、页面需求、组件需求、状态交互与验收边界  
**状态：** 设计文件，待评审后拆实施计划  
**定位：** 本文只定义“系统 UI 应该有哪些功能、怎么组织、怎么交互”。不定义最终视觉皮肤、颜色 token、动效细节和代码实现。

---

## 1. 设计原则

### 1.1 后台是运营系统，不是设置集合

新后台 UI 必须让管理员完成三类工作：

- 看清系统：运行状态、用量趋势、资源分布、风险告警。
- 管好能力：Provider、模型、RunningHub、节点能力、AI 助手。
- 管好组织：账号、分组、权限、审计、会话、用量。

### 1.2 每个页面遵循同一工作流

每个功能区都采用：

1. 先看概览。
2. 再筛选对象。
3. 再查看详情。
4. 再修改参数。
5. 再确认保存。
6. 最后通过审计和运行态确认影响。

### 1.3 无权限内容隐藏

普通用户无权限时，前台不展示对应资源、RH 条目或节点能力，不显示“拒绝使用”。后台只在权限治理页显示允许 / 禁用状态。

### 1.4 参数保存要可追踪

所有参数修改必须展示：

- 当前值
- 草稿值
- 未保存状态
- 保存状态
- 冲突状态
- 实际生效值
- 最近更新时间
- 审计记录

### 1.5 防溢出是功能需求

以下不是视觉细节，而是功能验收条件：

- 文本不能溢出容器。
- 按钮不能挤压到不可读。
- 卡片不能被动态内容撑坏。
- 页面不能出现无意义的双滚动条。
- 局部列表不能只剩一小块可滚动区域。

## 2. 全局系统 UI

## 2.1 全局框架

### 功能

全局框架负责承载所有后台模块，并提供统一导航、环境状态、搜索、告警、账号操作和 AI 助手入口。

### UI 区块

- 左侧一级导航
- 顶部状态栏
- 主工作区
- 右侧 AI 助手面板
- 全局弹窗层
- 全局提示层

### 左侧一级导航

一级导航包含：

- 运营总览
- 能力配置
- 资源与内容
- 组织与治理
- 系统与发布

每个导航项需要：

- 图标
- 中文名称
- 当前选中状态
- 未处理告警数量，可选
- 折叠态支持

### 顶部状态栏

顶部状态栏包含：

- 当前环境：gray / production / local
- 当前版本号
- API 连接状态
- 全局搜索
- 告警入口
- AI 助手开关
- 当前管理员账号
- 退出登录

### 主工作区

主工作区负责展示当前功能页面。页面内部固定使用：

- 页面标题区
- 页面说明区
- KPI 或摘要区
- 筛选 / 操作区
- 内容区
- Inspector 或详情区
- 保存 / 应用条

### 右侧 AI 助手面板

AI 助手需要支持：

- 展开 / 收起
- 读取当前页面上下文
- 读取当前选中对象摘要
- 接收结构化附件
- 输出排查建议、配置草案、变更摘要
- 高风险操作只给建议，不直接执行

### 状态

全局框架必须支持：

- 未登录
- 权限不足
- API 已连接
- API 断开
- 正在加载
- 有全局告警
- 有后台任务运行

### 功能

管理员可以从任意页面搜索后台对象。

### 搜索范围

- 用户邮箱
- 用户名称
- 用户备注
- 用户组
- Provider
- 模型显示名
- 模型 ID
- RH 标题
- RH catalogId

- 公共资源分类
- 任务 ID
- 审计 requestId
- 公告标题
- 环境同步对象

### 交互

- 输入后展示分组结果。
- 结果按工作域分组。
- 支持键盘上下选择。
- 点击结果进入对象详情。
- 搜索无结果时展示可搜索范围。

### 验收

- 长 ID 不撑宽搜索面板。
- 搜索结果必须显示对象类型。
- 同名对象必须显示辅助字段区分。

## 3. 运营总览

## 3.1 页面目标

运营总览是后台首页。它要让管理员在 30 秒内判断：

- 平台是否健康。
- 任务是否积压。
- 哪些能力使用最多。
- 哪些组或账号用量异常。
- 哪些配置最近变更。
- 哪些风险需要处理。

## 3.2 页面区块

### 环境健康条

展示：

- 当前环境
- 当前版本
- 服务状态
- 数据库状态
- Redis 状态
- Worker 状态
- 最近更新时间
- 活动告警数

交互：

- 点击数据库进入系统健康数据库区。
- 点击 Redis 进入系统健康 Redis 区。
- 点击 Worker 进入 Worker / 队列区。

### 核心 KPI 区

指标：

- 今日成功任务数
- 当前排队任务数
- 当前运行任务数
- 24h 失败任务数
- 启用 Provider 数
- 启用模型数
- 启用 RH 条目数
- 公共资源数
- 活跃会话数

交互：

- 每个 KPI 可点击下钻。
- KPI 需要显示与昨日或 7 日均值的变化。

### 能力用量区

展示：

- 图像成功数
- 视频成功数
- LLM 成功数
- 音频成功数
- RH AI 应用成功数
- RH 工作流成功数
- 能力占比
- 最近 10 天趋势

交互：

- 点击能力进入用量分析并自动筛选能力。

### 队列运行区

展示：

- 图片队列
- 视频队列
- 音频队列
- RH 平台窗口
- 总并发配置
- 单用户并发配置
- 实际生效并发
- Worker 数
- 槽位数

交互：

- 点击队列进入任务队列页。
- 点击并发进入运行参数页。

### 风险雷达区

展示：

- 失败趋势
- requestId 覆盖率
- revision 冲突
- Provider 失败
- RH Key 池风险
- 环境差异

交互：

- 点击风险进入告警详情。

### 最近变更区

展示：

- 最近账号变更
- 最近权限变更
- 最近 Provider / 模型变更
- 最近 RH 条目变更
- 最近资源变更
- 最近公告发布
- 最近系统参数变更

交互：

- 点击进入审计日志并锁定对象。

## 3.3 状态

- 数据加载中
- 部分数据加载失败
- 全部健康
- 有警告
- 有严重风险
- 无成功任务

## 4.5 RH 工作流

### 功能

与 RH AI 应用一致，但对象类型为 workflow。

额外要求：

- 显示 workflowId。
- 支持显式无入参工作流。
- 对 `nodeInfoList=[]` 的合法工作流不误判为缺少输入槽。
- 工作流与 AI 应用不能混用 ID。

### 状态提示

- 显式无入参，可运行。
- 有 schema 但缺少 RH 字段绑定。
- 有输入槽，可展开参数。
- app / workflow 混合态，禁止运行。
