# 新版画布呈现修正设计

## 背景

`v0.8.4` 已提供按用户切换的新旧画布呈现模式，但桌面验收发现三个问题：新版侧栏存在与悬停行为重复的开合按钮；既有图像、视频、LLM 节点没有被新版视觉完整接管；顶栏样式开关没有复用现有工具按钮的尺寸与视觉语言。

## 目标

- 新版侧栏只保留有实际动作的入口，鼠标悬停和键盘聚焦仍可临时展开。
- 开启新版后，已存在和新建的图像、视频、LLM 节点都使用同一套新版运行时视觉，而不迁移或重写节点数据。
- 顶栏的画布样式开关成为 32px 的紧凑分段控件，与公告、渠道状态、资源库和性能优化按钮对齐。
- 防止模型名、渠道名、错误详情和素材来源文案越界或覆盖其他控件。

## 非目标与不变量

- `legacy` 仍是默认模式；新版偏好仍按用户保存在浏览器本地。
- 不改变画布 JSON、节点类型、位置、连接、任务 payload、Provider 调用、素材数组、上游素材合并与回传逻辑。
- 不删除现有节点字段、操作按钮、运行状态卡、错误详情、素材管理、拖拽和 React Flow handles。
- 旧版画布的 DOM 结构和视觉表现不被新版 CSS 污染。

## 设计决策

### 1. 自动展开侧栏，不再提供重复的开合按钮

新版 rail 固定保留四个真实入口：画布列表、创建画布、节点搜索、AI 托管。面板以 hover/focus-within 临时展开，鼠标离开或焦点离开即收起。rail 不设置“收起/展开”按钮；这避免同一状态同时由自动行为与手动按钮控制。

### 2. 用标识化视觉适配层覆盖既有节点

三个生成节点根元素增加稳定的 `data-node-presentation` 和 `data-node-kind` 属性。它们继续使用原有 JSX、事件处理、模型选择、状态卡和素材组件；新版 CSS 仅在 `.t8-app-shell[data-canvas-presentation='modern']` 下以这些属性重排和放大控件。这样同一个已保存节点在新旧模式间即时切换，无需迁移、复制 state 或重新加载画布。

新版视觉层的分组语义是：节点头部、发布模型、核心参数、素材输入、文本描述、执行操作与运行结果。CSS 仅改变分组的边界、间距、排版和最大宽度，不隐藏字段。

### 3. 将样式切换器纳入顶栏控件系统

切换器显示为 `画布样式` 标签加 `旧版` / `新版` 两个等宽选项；`新版` 可带小型“预览”状态文字但不写入主按钮标签。整体高度 32px、圆角 8px、边框与间距复用顶部 action token；选中态使用低饱和青色高亮，避免与资源库和生成库的功能色竞争。

### 4. 文本和布局边界

节点标题 16px/22px，字段标签 13px/18px，输入值 14px/20px，辅助信息 12px/18px。模型、渠道和错误文本允许断词、最多两行收束；Prompt 与错误详情保持可读，不改为单行截断。所有 flex 子项使用 `min-width: 0`，输入和按钮不被长文本挤出节点。

## 验收标准

在 1920×1080 桌面环境：

1. 新版侧栏默认显示四个有效图标；hover 和 Tab 均可打开现有完整面板，离开后自动收起，画布不被挤压。
2. 切换新版时，现有图像、视频、LLM 节点立刻以新版字号、宽度、分组和防溢出规则呈现；切回旧版立即恢复原外观。
3. 模型选择、首帧/上游素材、Prompt、生成/停止、状态与错误卡仍可见且交互不变。
4. 顶栏样式开关与相邻按钮同高、同圆角、同间距，不覆盖窄屏已有响应式规则。
