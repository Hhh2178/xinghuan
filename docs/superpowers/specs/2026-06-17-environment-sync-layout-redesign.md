# 环境同步页布局重构设计

## 背景

当前后台“环境同步”页已经具备基础功能，但页面布局在真实数据量和右侧 AI 助手常驻打开的场景下出现了明显失控：

- 左侧同步设置与摘要区域过窄，文本被压缩到接近竖排阅读。
- 中间差异表本身列数较多，又要与右侧 AI 助手共享宽度，导致信息区块互相挤压。
- 页面滚动边界不清楚，主页面、差异表和右侧助手都在争夺整屏高度。
- 同步控制动作没有固定停留在视线顶部，长表滚动后会失去操作上下文。

这不是单个控件样式错误，而是页面结构边界不合理。当前布局将：

1. 左侧同步配置
2. 中间高密度对比表
3. 右侧常驻 AI 助手

同时放入同一层级做高度与宽度竞争，最终导致整体混乱。

## 目标

本轮只解决环境同步页的布局结构问题，不改变其核心业务能力。

目标：

1. 页面顶部保留固定参数和控制区。
2. 差异列表区域变成独立滚动工作区。
3. 保持右侧 AI 助手默认打开、可关闭的现状。
4. 让“账号 / 服务商（含模型）同步”在大数据量时仍可稳定阅读和批量操作。
5. 清晰划分：
   - 页面级固定区
   - 页面级滚动区
   - 助手面板区

## 非目标

- 不改环境同步的数据规则和接口协议。
- 不改右侧 AI 助手的信息结构和对话能力。
- 不新增自动同步、定时同步或新的同步对象。
- 不把差异表全面改造成卡片流产品。
- 不处理后台其他页面的布局问题。

## 问题归因

### 1. 横向空间分配错误

环境同步页当前是：

- 左边一个较宽的 sidebar
- 中间一个大表格区
- 右边一个常驻 AI 助手

但中间表格天然需要最大宽度，左侧 sidebar 又放了太多纵向内容，结果导致主表列宽不足。

### 2. 滚动职责混乱

当前存在多个潜在滚动层：

- `admin-main`
- 环境同步页内部布局
- 表格容器
- AI 助手消息区

当这些滚动层同时存在时，用户很难判断“当前滚的是整页、列表，还是某个侧栏”。

### 3. 信息层级错误

左侧“同步设置”和“本次操作摘要”承担了太多职责：

- 参数设置
- 操作按钮
- 结果说明
- 统计信息

导致左侧区域过高、过重，压缩了真正应该成为主工作面的中间差异表。

## 方案对比

### 方案 A：保留当前双栏结构，只做压缩和样式修补

做法：

- 保留左侧 sidebar + 中间表格
- 微调 spacing、按钮尺寸、文字换行
- 把 AI 助手相关区域稍微压窄

优点：

- 改动最小
- 上线最快

缺点：

- 只是缓解，不解决结构性问题
- 一旦差异表数据量增大，仍然会再次挤压
- 左侧区域继续过重

结论：

- 不采用

### 方案 B：固定控制台 + 下方独立滚动工作区

做法：

- 顶部新增固定控制区
- 下方主工作区分为：
  - 左窄栏：摘要与批量操作
  - 右主栏：差异表
- 差异表区域独立滚动
- 右侧 AI 助手继续作为外侧常驻面板存在

优点：

- 最符合当前工作流
- 清楚划分固定区和滚动区
- 兼容高密度表格对比场景
- 对现有数据结构改动最小

缺点：

- 需要重新组织环境同步页 DOM 结构和 CSS

结论：

- 采用本方案

### 方案 C：把差异表全面改成卡片流

做法：

- 所有账号 / 服务商项改成卡片
- 不再以大表格作为主呈现

优点：

- 视觉更轻
- 移动端更自然

缺点：

- 对高密度对照和批量决策不友好
- 在服务商 + 模型摘要场景下效率明显下降

结论：

- 本轮不采用

## 最终设计

采用方案 B：

- 顶部固定控制区
- 下方独立滚动工作区
- 工作区内部为“左摘要窄栏 + 右主表”
- AI 助手继续常驻右侧，且不再参与环境同步页内部布局逻辑

## 页面结构

环境同步页调整为三层：

### 第一层：页面 Hero

保留页标题与简短说明，但压缩为轻量顶部信息，不再占大块高度。

内容：

- 页面标题
- 一句话说明
- 三个状态指标：
  - 已选项
  - 账号差异数
  - 服务商差异数

要求：

- 高度控制在一屏内的轻量头部
- 仅承担“说明当前页面是什么”的职责

### 第二层：固定控制区

这是本轮的核心变化。

该区域始终固定在环境同步页顶部，不随差异表滚动。

包含：

- 源环境选择
- 目标环境选择
- 左右互换
- 先查看差异
- 确认同步
- 当前同步方向
- 冲突数 / 已选数

要求：

- 该区必须是稳定的一行或两行布局
- 不允许再出现纵向很长的参数面板
- 所有关键动作始终在视线顶部

### 第三层：主工作区

主工作区占据顶部固定区以下的剩余高度，自己滚动。

结构：

- 左窄栏
- 右主栏

#### 左窄栏

宽度固定在一个适中的范围，作为工作辅助栏，而不是主阅读区。

内容：

- 本次操作摘要
- 当前进度
- 批量操作
  - 全选账号
  - 清空账号
  - 全选服务商
  - 清空服务商

约束：

- 只展示摘要和批量控制
- 不再承载长文本明细
- 不再放完整左右环境数据

#### 右主栏

作为真正的主工作面，承担：

- 账号差异表
- 服务商（含模型）差异表
- 同步结果表

约束：

- 右主栏获得大部分宽度
- 列表区域独立滚动
- 账号 / 服务商标题与表头始终清晰

## 表格策略

当前环境同步不适合改成纯卡片流，因此保留表格，但要重构表格信息密度。

### 列结构

保留以下核心列：

- 勾选
- 对象
- 状态
- 左侧摘要
- 右侧摘要
- 决策

### 信息压缩规则

主表中只保留摘要，不再直接展示过长的完整文本块。

例如：

- 用户：邮箱 / 名称 / 角色 / disabled / hasPassword
- Provider：名称 / 启用状态 / 协议 / 模型数量 / 差异摘要

模型相关信息在主表中只保留统计级摘要，例如：

- 左侧模型数
- 右侧模型数
- 仅左侧
- 配置不同
- 一致数
- 仅右侧

### 表头行为

表头应为 sticky，至少在右主栏滚动时保持：

- 选择
- 对象
- 状态
- 左侧环境
- 右侧环境
- 决策

始终可见。

## AI 助手共存策略

本轮明确不改变产品要求：

- 右侧 AI 助手桌面端默认打开
- 用户可主动关闭

但要改变页面之间的责任边界：

- 环境同步页内部只处理自己的固定区和滚动区
- 右侧 AI 助手只作为 `admin-workspace` 的外部固定列存在
- 环境同步页不再试图和 AI 助手共享内部布局逻辑

这意味着：

- 环境同步页要天然适配“右侧存在一列常驻面板”的宽度
- 页面内部禁止再出现一个过宽的左侧 sidebar

## 响应式策略

### 桌面端

- 保持右侧 AI 助手常驻
- 环境同步页使用：
  - 顶部固定控制区
  - 下方左右工作区

### 中等宽度

- 若宽度不足以支撑“左窄栏 + 右主栏 + 助手面板”三者舒适共存
- 则左窄栏进一步收缩
- 但仍优先保证右主栏宽度

### 窄屏 / 移动端

- 右侧 AI 助手改为 overlay / 抽屉行为，沿用现有全局机制
- 环境同步页内部退化为单列：
  - 顶部固定控制区
  - 摘要区
  - 差异表

## 组件调整建议

### `AdminEnvironmentSyncPanel`

需要从当前“hero + 左 sidebar + 右 content”的思路，改成：

- hero
- fixed controls
- workspace
  - summary rail
  - table area

建议拆出几个内部区域：

- `environment-sync-toolbar`
- `environment-sync-workspace`
- `environment-sync-rail`
- `environment-sync-table-area`

### 样式层

当前样式问题之一是环境同步页过度依赖通用 panel 风格拼接。

本轮建议增加专门样式分层：

- 顶部固定控制区样式
- 工作区 grid 样式
- rail 样式
- 表格区域 sticky header 样式

这样能避免继续通过已有 sidebar / panel 样式硬拼。

## 交互流程

新的推荐工作流：

1. 用户进入环境同步页
2. 顶部直接设置：
   - 从哪里复制
   - 同步到哪里
3. 点击“先查看差异”
4. 下方工作区展示：
   - 左侧摘要
   - 右侧差异表
5. 用户在右侧主表中完成：
   - 勾选
   - 决策
6. 顶部固定区始终可见，用户可以随时点击“确认同步”
7. 同步结果区在主表下方或替换展示，不打断顶部操作

## 测试要求

### 布局测试

至少验证：

1. 在 AI 助手打开时，环境同步页不出现内容重叠
2. 顶部控制区固定可见
3. 右主栏表格可以独立滚动
4. 左侧摘要栏不出现被压缩到竖排阅读的情况
5. 表头 sticky 正常

### 交互测试

1. 左右互换仍可用
2. 查看差异仍可用
3. 确认同步仍可用
4. 全选 / 清空账号可用
5. 全选 / 清空服务商可用
6. 决策下拉可用

### 回归测试

1. 右侧 AI 助手打开 / 关闭切换不影响环境同步页主布局
2. 其他后台页不被这次 CSS 变更污染

## 风险与控制

### 风险 1：CSS 波及其他后台页

控制：

- 新样式必须加环境同步页专属前缀
- 避免复写全局 panel / table 公共规则

### 风险 2：表格信息压缩后丢失判断依据

控制：

- 主表展示摘要
- 保留状态和关键字段
- 长内容通过二级查看或 tooltip 解决，而不是直接在主表铺开

### 风险 3：固定控制区高度过大

控制：

- 控制区只放参数和主动作
- 进度说明与统计信息压缩成状态 chip / summary

## 完成标准

本轮完成的判断标准：

1. 环境同步页顶部存在固定控制区。
2. 差异列表在下方独立滚动。
3. AI 助手常驻打开时，页面不再出现明显重叠和错位。
4. 左侧区域只承担摘要和批量操作，不再压缩主表。
5. 页面在真实账号 / 服务商差异数据下仍然可读、可操作。
