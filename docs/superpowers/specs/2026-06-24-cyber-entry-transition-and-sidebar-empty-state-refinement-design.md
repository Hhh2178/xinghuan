# Cyber Entry Transition And Sidebar Empty State Refinement Design

## 背景

`v0.5.1` 的入口视觉换肤已经把登录页、主过渡页、空画布中心卡牌和左上品牌区切到新的 Cyber PCB 语言，但当前仍有两个残留问题：

- 登录后加载链路中还会短暂出现一个“正在展开星幻工作区”的旧 fallback 页面，导致过渡阶段出现两套视觉壳层。
- 侧边栏左上“还没有星图画布”的小卡片仍然沿用旧的小面板表达，没有与中间主空态卡牌保持同一视觉体系。

## 目标

本轮只收口两个点：

1. 删除多余的工作区 fallback 可见页面，让启动链路只保留一套 `CyberTransitionStage`。
2. 将侧边栏无画布卡片改造成“侧边栏尺寸版”的 Cyber 空态卡片，和中间“开启第一张星图”主卡统一语言。

## 方案

采用方案 1：

- 直接去除“正在展开星幻工作区”这个旧 fallback 的可见壳层。
- 不保留第二套占位文案页，也不再做弱化版 fallback。

原因：

- 视觉最干净。
- 启动链路只剩一套状态表达，不会再出现“过渡页里又套一个过渡页”的感觉。
- 改动面可控，只落在前端壳层与局部样式。

## 具体设计

### 1. 过渡链路收口

文件：`apps/web/src/App.tsx`

- 删除 `WorkspaceShellFallback` 里的“正在展开星幻工作区”文案卡片壳层。
- `Suspense fallback` 不再渲染旧页面。
- 启动期间继续只使用 `CyberTransitionStage`。

实现口径：

- `authStatus === "checking"` 和 `bootSplashVisible` 仍然返回 `CyberTransitionStage`。
- 懒加载期间不再额外暴露一张旧风格工作区 fallback 卡片。

### 2. 侧边栏空态卡片统一

文件：`apps/web/src/components/Sidebar.tsx`

- 将当前“还没有星图画布”块改造成侧边栏版 Cyber 卡片：
  - 顶部 chrome
  - 切角硬边框
  - 小标签 / kicker
  - 白色主标题
  - 次级说明
  - 与主空态一致风格的高亮按钮
- 保持内容简洁，不复制中间主卡的全部细节模块。

实现口径：

- 它是“中间主卡的小型侧栏适配版”，不是把主卡生硬缩放塞进侧边栏。
- 保持信息层级一致，但尺寸、字重和间距按侧边栏密度重排。

### 3. 样式边界

文件：`apps/web/src/styles/index.css`

- 新增 `xh-sidebar-empty-card*` 一组局部样式。
- 不复用旧的 `xh-sidebar-empty` 轻提示块样式。
- 不改中间 `EmptyCanvasSplash` 的主卡结构，只对侧边栏新增一套同语言适配层。

## 不在本轮范围

- 不改登录页主视觉。
- 不改中心空画布主卡结构。
- 不改过渡页文案与进度机制。
- 不改侧边栏其他节点分组、搜索和画布列表逻辑。

## 验证

Agent 负责：

- `@xinghuan/web` 类型检查
- 相关 contract 校验
- 本地预览和实际工作区无报错
- 确认加载链路中不再出现旧 fallback 页面

用户负责：

- 新侧栏空态卡片是否与中间主卡风格一致
- 过渡阶段观感是否足够干净

## 结论

本轮按方案 1 收口：

- 去掉旧 fallback 页面
- 把侧边栏空态卡片统一成主空态卡的同语言侧栏版本

这样可以在不动业务逻辑的前提下，把入口链路和无画布状态的视觉一致性补齐。
