# Admin 渐变科技操作台与画布表现层回撤设计

## 结论

上一轮“新版画布”没有形成真实的节点结构：节点 DOM、数据模型、字段编排和交互保持不变，只叠加了 `modern` CSS 覆盖。因此历史节点与新节点都只会被横向拉宽，不能称为新节点设计。本方向退出；画布不再维护新旧切换、节点现代样式或用户级视觉状态。保留已验证有效的悬停展开侧边栏，并将其作为唯一侧栏形态。

Admin 已有 12 个工作域、25 个稳定子视图、Token 文档和组件注册表，但规则分散在根设计文档、十余份子规范、页面级皮肤与 `apps/admin/src/styles.css`（9,079 行）中。Token 没有成为“先读再改”的唯一入口，同类表单、卡片、页头、rail 和状态面由多套尺寸、圆角、渐变和字号驱动。

## 目标

1. 画布只保留自动展开的悬浮侧边栏；恢复既有节点、点阵、MiniMap 与浮层外观，移除选择器、持久化状态、节点 modern CSS 和无效 marker。
2. Admin 统一为“深海青—蓝色渐变科技操作台”：渐变只负责品牌层级，不承担业务状态；表单、告警、日志、表格保持高可读性。
3. 建立唯一的 Admin 视觉基础、全页面审计、重构程序和入口索引。以后涉及 Admin UI 的改动，必须先阅读这些资料，并声明复用的 Token 与组件。
4. 不改变 Admin 信息架构、稳定 URL、权限、读写、刷新策略、任务链路或发布能力；不安装新 UI 框架。

## 视觉治理架构

| 层 | 权威文件 | 职责 |
| --- | --- | --- |
| Foundation | `visual-foundation.md` | 色域、渐变、字号、间距、圆角、阴影、状态与禁用清单 |
| Audit | `admin-page-visual-audit.md` | 12 个工作域及子视图的现状、问题、目标模板与验收点 |
| Program | `redesign-program.md` | 工作域优先级、共享组件边界、迁移与发布顺序 |

`DESIGN.md` 保留跨产品原则；Admin README 成为 Admin 专用强制阅读入口。页面改动先读 Foundation 与 Audit，再查 Registry。新颜色、字号、圆角、间距或组件不得绕过此路径。

## 目标视觉语言

- 底色：深蓝黑 `#06111b` 至 `#0a1626`，不使用纯黑大块切割页面。
- 品牌渐变：青 `#35e6da` → 天蓝 `#4f9cff`，仅用于 Shell、页头、当前导航、关键摘要和主按钮的轻量高光。
- 内容面：表单、表格、日志和长文本使用中性深面 `#0d1a2a` / `#101f31`。
- 语义色：success、warning、danger 独立，渐变不表示成功或失败。
- 层级：每页只有一个工作域页头；配置页为“上下文 → 字段组 → 影响说明 → 保存差异”；运营页为“异常摘要 → 核心状态 → 趋势 → 明细 → 技术详情”。
- 字体：H1 24px，区块 18px，面板 16px，正文 14px，标签 13px，Meta 12px；11px 不能承载操作说明或失败原因。

## 画布回撤设计

1. 删除 `CanvasPresentationToggle`、presentation Zustand store 与用户本地持久化键；顶栏不再出现旧版/新版控制。
2. `App` 不再向 Canvas 传入 presentation，也不写入 `data-canvas-presentation`。
3. Canvas 恢复原有背景点阵、MiniMap 与 overlay 规则；去除 presentation prop 和现代 grid 变量。
4. Sidebar 默认使用 `t8-sidebar--modern`：rail 宽 56px，悬停或键盘焦点展开至 232px，只含画布列表、新建、节点搜索、AI 托管四个真实动作。
5. 删除 `node-modern.css` 和 Image/Video/LLM 的 modern marker；不改变节点数据、表单、素材管理、事件或任务提交。

## 风险与验收

- 高风险保存、同步、发布与删除继续使用影响范围和二次确认，渐变不得伪装为状态色。
- 既有 `guarded/manual/live` 刷新策略保持，视觉重构不得覆盖草稿。
- 长 ID、URL、错误、日志和 Schema 必须安全换行或进入可复制 Inspector。
- 默认仅验收 PC 1920×1080；保留现有响应式降级，不新增移动端产品设计。
- 顶栏不存在新旧切换；浏览器旧本地存储不影响画布。
- 新旧节点均恢复既有结构；MiniMap、点阵、悬浮层正常。
- 三个 Admin 基础文件可从 `docs/INDEX.md`、`DESIGN.md`、Admin README 到达，并由 Harness 校验。
