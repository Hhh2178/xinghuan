# Admin 健康页视觉精修与公共资源拆域计划

状态：已完成并发布 Gray
日期：2026-07-21
目标环境：Local → Gray
版本：保持 `v0.7.17`
禁止环境：Production

## 目标

1. 让系统健康页继承 Provider 页面已经形成的 Starlight 空间层级、细描边、深蓝内容面、中文状态与高密度桌面信息表达。
2. 把原先无坐标、无摘要、难解释的简易趋势线升级为带数值摘要、刻度、网格、时间轴、单位和数据来源的可读图表。
3. 把五个同权重卡片收敛为单一运行态势面板，降低“组件拼盘”感，同时保留领域下钻。
4. 把公共资源从“内容与资源”拆成独立一级工作域；公告归入独立的“内容发布”工作域。

## 实施步骤

1. 对照用户截图、`DESIGN.md`、Admin Token 与系统健康可视化标准完成视觉差异审查。
2. 重构健康页首屏为“运行态势 → 活动告警 → 五域摘要”，统一状态文案、背景、描边和控件。
3. 重做固定服务链路、任务趋势和容量 bullet bar，补齐刻度、单位、阈值和数据新鲜度。
4. 新增 `resources` 一级工作域和 `/admin/resources` 稳定路由；保留旧 `/admin/content/public-resources` 兼容解析。
5. 更新信息架构、页面地图、契约和本计划状态。
6. 运行 Admin type-check、build、导航/健康页/设计规范契约、全量测试与快速门禁。
7. 保持 `v0.7.17` 发布到 Gray，执行桌面浏览器、console、API、Worker 和 release readiness 验证。

## 验收标准

- 健康页与 Provider 页面使用相同的标题层级、青色细描边、深蓝内容面、按钮和状态表达。
- 首屏不再出现五张同权重的大卡片；活动告警和总体状态优先。
- 趋势图具备摘要、Y 轴刻度、网格、时间标签、单位和数据来源。
- 容量条同时表达实际槽位、配置上限、队列深度、Worker 数和安全阈值。
- 公共资源在侧栏拥有独立入口，公告页面不再与公共资源共享工作域。
- 旧公共资源深链仍能解析到新工作域。
- Gray 验证通过且 Production 版本、release 和服务状态不变。
