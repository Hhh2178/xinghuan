# 画布生成节点本次费用展示实施计划

> 日期：2026-07-21  
> 目标环境：Gray only  
> Production：保持 v0.7.13，不部署、不修改

## 目标

在图片、视频、LLM、音频及后续使用后台模型目录的生成节点左上角展示统一费用窗口。后台没有有效计费配置时完全隐藏；切换 Provider 或模型时立即切换当前报价；任务开始后使用任务费用快照展示计算中和最终结算金额。

## 数据权威

1. `/api/models` 在既有权限过滤后，为每个模型附带当前有效且启用的最小价格摘要。
2. 前端报价只用于执行前提示；按次展示单次金额，按秒在节点有明确时长时展示当前预计金额，否则展示每秒价格。
3. 任务 INSERT 继续由 Migration 025 的触发器锁定价格版本和归属快照。
4. 新增 owner-scoped 批量任务费用摘要接口，只返回当前用户任务的展示级状态、金额、币种、计费单位和模型快照 ID。
5. 节点最终金额只读取任务费用项；后台改价、用户换组或画布重载不得重算历史。

## 交互状态

| 条件 | 节点费用窗口 |
|---|---|
| 当前模型无有效计费配置 | 不渲染窗口和金币图标 |
| 当前模型已配置、尚未执行 | `预计 ¥x` 或 `¥x/秒` |
| 本次任务费用项 pending | `计算中` |
| charged | 展示本次任务或批次合计金额 |
| not_charged | `¥0` |
| 有价格快照但缺少按秒权威时长 | `待核算` |
| 任务费用模型与当前选择不一致 | 忽略旧结算，展示当前选择报价 |

## 实现分层

### API / Storage

- 扩展 `task-cost-repository`：owner-scoped 批量费用读取和安全聚合。
- 新增画布用户费用路由，不复用管理员权限路由。
- 扩展公共模型目录价格摘要；禁用/不存在价格时省略字段。
- 外部 LLM 同步路径返回已写入任务的 `taskId`，前端保存以读取最终费用。

### Canvas Web

- 新增共享 `NodeCostBadge`、费用展示纯函数和 API 类型。
- 在现有单一节点宿主内渲染，不增加 ReactFlow 并列根节点。
- 从 `backendModelId` 解析当前目录模型和价格；从 `taskId/taskIds` 查询本次费用。
- 图片、视频、LLM、音频以及未来使用相同数据契约的生成节点自动复用。

### 视觉

- 22–24px 高度的小型胶囊；12–14px `Coins` 线性图标。
- 使用 Canvas elevated surface 和低饱和琥珀色边框/文字；11px 运行态字号、等宽金额数字。
- 固定在节点左上角，与右上角 NodeID 徽标对称，不遮挡端口，不参与点击。
