# v0.1.0 Release

## 版本定位

v0.1.0 是无限画布 2.0 的立项与选型准备版本，不是可上线产品版本。

## 范围内

- 项目治理文件。
- 需求文档。
- 技术 SPEC。
- 设计方向。
- 开发计划。
- 进度记录。
- 决策台账。

## 范围外

- 不包含可运行代码。
- 不包含服务器部署。
- 不包含真实 Provider 调用。
- 不包含数据库迁移。

## 验收清单

- `AGENTS.md` 存在并包含协作规则。
- `MEMORY.md` 存在并包含旧项目放弃原因和 2.0 核心需求。
- `DEVLOG.md` 存在并包含初始化记录。
- `docs/prd/README.md` 存在并标记当前活跃版本。
- `docs/prd/v0.1.0/` 文档完整。

## 发布结论

当前版本用于指导后续选型和 POC，不建议直接进入功能开发。必须先完成候选基底评估。
