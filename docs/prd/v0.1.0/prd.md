# 无限画布 2.0 PRD

## 1. 背景

旧无限画布项目在 Node Banana 基础上进行了大量改造，但基础节点体系薄弱，新增节点、模型后台、云端项目和任务执行链路难以形成一致体验。继续修补会持续消耗时间，且难以通过完整验收。

因此启动“无限画布 2.0”新项目：重新选择或搭建更适合公司内部 AIGC 工作流的基底，从第一天就围绕节点插件化、模型后台、云端项目、用户隔离和异步任务执行设计。

## 2. 项目目标

- 为公司内部成员提供成熟 Web 化无限画布创作平台。
- 支持图片、视频、文本、音频等 AIGC 任务的节点式工作流。
- 后台统一管理外部 API Provider、模型、参数、能力和密钥。
- 项目、素材、任务和输出结果保存到云端服务器，并按用户隔离。
- 节点系统可持续扩展，后续新增节点不再造成大规模核心改动。

## 3. 用户角色

- 普通成员：创建项目、上传素材、搭建工作流、调用已发布模型、查看自己的素材和任务。
- 开发者：调试 Provider、模型 schema、节点定义、任务执行和日志。
- 管理员：管理用户、权限、服务商、模型、密钥、配额、审计和系统状态。

## 4. 核心需求

### P0 - 基底与架构

- 选择或搭建具备稳定无限画布、节点扩展和执行链路的项目基底。
- 前后端结构清晰，支持独立后台、API、数据库、队列和 worker。
- 支持腾讯云 VPS 部署，能通过 Nginx 和 HTTPS 对外访问。

### P0 - 节点工作流

- 支持节点新增、拖拽、连接、删除、复制、分组、缩放和平移。
- 节点类型包括输入、生成、处理、控制流、输出、素材、批量和 Agent。
- 节点连接必须有类型系统，不能混接图片、视频、文本、音频和 JSON。
- 支持拓扑执行、部分执行、失败传播、取消和重试。

### P0 - 通用生成节点

- 图像生成节点不是 GRSAI 专属节点，而是通用图像生成节点。
- 节点内可选择 Provider、模型和参数。
- 参数和输入端口由后台模型 schema / input profile 驱动。
- 视频生成、文本生成、音频生成也采用同样通用节点模式。

### P0 - 模型与服务商后台

- 管理员配置 Provider 名称、协议、Base URL、API Key、健康检查和启停。
- 支持自动发现模型，也支持手动录入模型。
- 每个 Provider 互相隔离，Key 和模型不互相污染。
- 模型支持能力标签、参数 schema、默认值、输入 profile、输出类型和成本配置。
- 后台页面仅管理员和开发者可访问。

### P0 - 云端项目与素材

- 项目、画布、工作流、素材、任务和输出结果保存到服务器。
- 用户之间项目和素材隔离。
- 支持项目列表、画布列表、工作流版本、素材库和生成历史。
- 本地文件只作为导入/导出备份，不作为主保存方式。

### P0 - 任务系统

- API 请求进入任务队列，由 worker 异步执行。
- 任务状态包含 queued、running、succeeded、failed、cancelled。
- 支持任务取消、重试、日志、耗时、Provider、模型和参数快照追踪。
- 成功输出自动进入项目素材空间。

### P1 - Agent 创作模式

- 参考 Jaaz 的 Agent 模式，为用户提供创作建议、节点搭建辅助和 prompt 辅助。
- Agent 不能绕过权限和 Provider 管理。

### P1 - T8 风格能力

- 参考 T8 的节点组织、素材管理、跨画布发送、运镜组合和批量执行。
- 视频创作优先支持首帧、尾帧、多参考图、镜头参数和批量生成。

### P1 - 插件节点体系

- 参考 ComfyUI 的插件节点思想。
- 节点定义、参数、输入输出、UI、执行器注册应集中管理。
- 后续新增节点应尽量做到新增插件文件和注册表配置即可。

## 5. 非功能需求

- 界面风格：科技黑、黑绿/青绿色强调、内部生产工具质感。
- 默认中文，后续可扩展英文。
- UI 字号默认比旧项目放大约 `1.5x`，支持用户设置。
- 图片和视频节点必须保持素材宽高比，禁止任意拉伸变形。
- 所有密钥脱敏显示，加密保存。
- 操作日志、任务日志和错误日志可查询。
- 目标初期服务器为 2 核 3.6 GiB 腾讯云 VPS，不能设计成必须本地跑模型。

## 6. 验收标准

- 普通成员能登录、创建项目、上传素材、添加通用图像生成节点、选择已发布模型、执行任务并看到输出素材。
- 管理员能在独立后台配置 Provider、导入或录入模型、编辑参数 schema 和输入 profile。
- 图像模型支持多参考图时，节点能自动展示多个参考图端口。
- 视频模型支持首尾帧时，节点能展示首帧和尾帧端口。
- 不同用户无法看到彼此项目和素材。
- 任务失败时能看到失败原因和日志。
- 代码仓库、文档、日志和部署记录可追溯。
