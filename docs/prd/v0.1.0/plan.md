# 无限画布 2.0 开发计划

## 状态

规划中。

## Phase 0 - 选型与 POC

目标：确定可作为 2.0 主干的技术基底，或确认需要自研核心画布和节点系统。

任务：

- 建立候选项目评估表。
- 评估 Jaaz、T8、ComfyUI Web 类项目、React Flow 类项目、LiteGraph 类项目和其他候选。
- 检查许可证、维护状态、前后端结构、节点系统、执行引擎和部署成本。
- 选择 1-2 个候选做最小 POC。

验收：

- 至少产出一份候选基底评估报告。
- 至少完成一个能添加节点、连接、保存、执行 mock 任务的 POC。

## Phase 1 - 基础平台

目标：完成企业 Web 平台基础能力。

任务：

- 登录、账号、RBAC。
- 项目、画布、工作流、素材数据模型。
- 云端保存和打开。
- 独立后台框架。
- 科技黑工作台和后台基础 UI。

验收：

- 普通成员可以创建项目并保存云端画布。
- 管理员可以进入后台。
- 用户项目隔离生效。

## Phase 2 - 节点与模型治理

目标：完成通用生成节点和模型后台闭环。

任务：

- 节点注册表和类型系统。
- Provider 管理。
- 模型目录。
- 参数 schema 编辑器。
- input profile 编辑器。
- 通用图像生成节点。
- 通用视频生成节点。

验收：

- 管理员能配置 GRSAI 图像模型。
- 成员能通过通用图像节点生成图片。
- 多参考图端口能按后台配置动态出现。

## Phase 3 - 任务与素材闭环

目标：完成异步任务、worker、日志和输出素材落库。

任务：

- 任务状态机。
- 队列和 worker。
- Provider Adapter。
- 任务日志。
- 取消和重试。
- 输出素材落库。

验收：

- 任务成功、失败、取消、重试都可追踪。
- 输出素材能在项目素材空间查看。

## Phase 4 - 创作增强

目标：补齐视频创作、批量、运镜和 Agent 能力。

任务：

- 首帧/尾帧视频节点。
- 多参考素材节点。
- 批量执行和拓扑执行。
- 运镜组合节点。
- Agent 辅助搭建工作流和 prompt。

验收：

- 用户能从素材到视频生成完成一个可复用工作流。
- Agent 能辅助创建或解释工作流，但不绕过权限。

## 开发原则

- 每个 Phase 必须可验收，不做“看起来做了但入口找不到”的功能。
- 代码提交和文档更新同步进行。
- 先打通一个真实 Provider，再扩展多个 Provider。
- 先保证节点体系正确，再堆节点数量。
