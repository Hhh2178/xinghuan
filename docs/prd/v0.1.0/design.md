# 无限画布 2.0 设计文档

## 1. 视觉方向

- 背景：科技黑，接近 `#07090D`。
- 主强调：青绿或荧光绿，接近 `#36F6B4` / `#42D9FF`。
- 信息层级：工作台克制、密度高、便于长期使用。
- 后台：仪表盘 + 表格 + 抽屉编辑器，避免画布侧栏堆满管理功能。

## 2. 信息架构

```
登录
└─ 工作台
   ├─ 项目列表
   ├─ 无限画布
   │  ├─ 节点工具栏
   │  ├─ 节点画布
   │  ├─ 属性面板
   │  ├─ 素材空间
   │  └─ 任务面板
   └─ 用户设置

后台 /admin
├─ 总览仪表盘
├─ 用户与权限
├─ Provider 管理
├─ 模型目录
├─ 模型实验室
├─ 节点目录
├─ 任务监控
├─ 素材审计
├─ 运行日志
└─ 系统设置
```

## 3. 工作台布局

```
┌────────────────────────────────────────────────────────────┐
│ 顶栏：项目名 / 保存状态 / 运行 / 后台入口 / 用户             │
├──────────┬──────────────────────────────────────┬──────────┤
│ 工具栏   │ 无限画布                              │ 属性面板 │
│ 输入     │                                      │ 模型     │
│ 生成     │   [节点]──[节点]──[输出]              │ 参数     │
│ 处理     │                                      │ 输入口   │
│ 控制     │                                      │ 日志     │
├──────────┴──────────────────────────────────────┴──────────┤
│ 底部：任务队列 / 当前执行 / 错误提示 / 素材快捷区             │
└────────────────────────────────────────────────────────────┘
```

## 4. 通用生成节点 UI

节点标题：

- 图像：`通用图像生成`
- 视频：`通用视频生成`
- 文本：`通用文本生成`
- 音频：`通用音频生成`

节点内容：

- Provider 选择。
- 模型选择。
- 动态参数区。
- 动态输入端口提示。
- 输出预览。
- 最近一次任务状态。

动态端口示例：

```
参考图 1 ─┐
参考图 2 ─┤
提示词   ─┤ [通用图像生成] ─ 输出图片
mask     ─┘
```

## 5. 后台设计

后台必须是独立 Web 页面：

- 左侧导航固定。
- 主区域按模块显示表格、图表和编辑面板。
- Provider 和模型配置支持测试按钮、发现按钮和保存按钮。
- 模型 schema 编辑器要能配置参数类型、枚举值、默认值、范围、必填和可见条件。
- 模型 input profile 编辑器要能配置输入端口数量、类型和显示名称。

## 6. 素材空间

素材需要按项目和用户隔离：

- 输入素材。
- 输出素材。
- 收藏素材。
- 失败任务关联素材。
- 来源节点和任务 ID。

## 7. 交互要求

- 上传图片和视频后节点按素材比例展示。
- 手动缩放也必须保持素材比例。
- 连接不兼容类型时，端口高亮拒绝，不允许连线落地。
- 任务运行中节点显示状态，不阻塞整个画布。
- 错误信息要能展开查看，但默认不打扰画布操作。
