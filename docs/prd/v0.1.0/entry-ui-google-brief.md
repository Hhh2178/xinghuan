# 星幻画布入口 UI 重设计 Brief（给 Google/Gemini 前端使用）

## 1. 背景与目标

星幻画布是公司内部节点式 AIGC 创作平台，不是营销官网。入口页需要表达“专业、科技、可长期使用、可信赖”，同时不要堆砌概念文案、品牌标签或过重特效。

当前左侧视觉方案不合格：视觉偏廉价，星云深度感不足，背景网格和几何线条过多，整体像模板化科技背景。需要重新设计登录首页和进入工作区前的入口体验。

本次参考用户提供的 UI 设计文件包 `stitch_ui_optimization_and_transitions`：

- `stellar_canvas_internal/DESIGN.md`：采用其中的深空色板、磨玻璃面板、青绿/青蓝强调色、慢速氛围动效和内部生产工具定位。
- `_2/code.html` 与 `_2/screen.png`：采用“深色星云背景 + 磨玻璃登录卡片 + 鼠标跟随光场”的交互方向。
- `_1/code.html`：只参考“进入工作区前的短暂状态过渡”思路，不直接采用中心 logo、远程背景图、坐标/延迟文字和白闪爆发。
- `_1/screen.png`：截图接近白屏，不能作为视觉基准，后续实现不得依赖外链图片加载效果。

必须注意：参考设计稿不是最终成品，不能逐像素照搬。它的白色输入框、中心品牌图标、SSO/组织网络占位、`2024` / `Alpha` 页脚、坐标延迟信息和远程 Google 图片 URL 都不适合进入正式入口页。

目标页面：

- 左侧：抽象、轻量、有深度感的伪 3D 星云 / 星域视觉。
- 右侧：清晰、克制、磨玻璃质感的登录卡片。
- 整体：科技黑 + 青绿 / 青蓝主色调，少量冷白高光，避免紫色主导。
- 页面不出现营销式大标题，不出现说明堆叠，不出现开发过程描述。

## 2. 产品与品牌气质

关键词：

- 内部生产工具。
- AIGC 节点画布。
- 星域、计算、模型、任务、素材库。
- 克制、精密、可信、深色科技。
- 高级但不炫技。

反关键词：

- 赛博朋克灯牌。
- 游戏 UI。
- 区块链 / Web3 视觉。
- 过度发光、过度粒子、过度文字。
- 紫色渐变模板。
- 科技海报式大标题。

## 3. 页面结构

桌面布局：

```text
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│   左侧 58%-64%：抽象伪 3D 星云 / 微缩星系星图                  │
│   - 无文字                                                    │
│   - 无 logo                                                   │
│   - 无标签 chip                                               │
│   - 可有轻微空间深度、薄雾、远近星点、柔和光晕                 │
│                                                              │
│                          右侧 36%-42% ┌───────────────────┐   │
│                                       │ 登录卡片           │   │
│                                       │ 进入创作星域       │   │
│                                       │ 账号邮箱           │   │
│                                       │ 访问密钥           │   │
│                                       │ 进入星幻工作区     │   │
│                                       └───────────────────┘   │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

构图要求：

- 登录卡片不能永远居中悬浮在画面正中，桌面端应偏右，左侧留出足够星域空间。
- 左侧视觉不做解释文字，不承担品牌口号，只负责营造“进入星图工作台”的空间感。
- 画面整体要有横向张力，避免像一张居中的登录弹窗。

移动布局：

- 登录卡片优先可用，视觉区变为背景氛围，不占用过多首屏高度。
- 不允许出现横向滚动。
- 星云视觉可以弱化，但不能完全变成纯色背景。

## 4. 色彩基调

主背景：

- `#030611` 深空黑蓝。
- `#061526` 深海军蓝。
- `#041F1B` 深青绿黑。

主强调色：

- `#36F6B4` 荧光青绿，用于关键状态、按钮亮面、焦点。
- `#42D9FF` 冷青蓝，用于边框、高光、星点。

辅助色：

- `#A7F3D0` 柔和青绿文字或弱高光。
- `#CFFAFE` 冷白蓝，用于少量明亮星点和标题。
- `#64748B` / `#94A3B8` 用于次级文字。

禁用或慎用：

- 不要以紫色作为主视觉。可以极少量用于按钮末端过渡，但不能让页面看起来是紫色主题。
- 不要使用大面积纯黑 `#000000`。
- 不要使用高饱和红、橙、粉作为入口主色。

推荐 CSS 变量：

```css

  --xh-bg-0: #030611;
  --xh-bg-1: #061526;
  --xh-bg-2: #041f1b;
  --xh-cyan: #42d9ff;
  --xh-mint: #36f6b4;
  --xh-ice: #cffafe;
  --xh-muted: #94a3b8;
  --xh-panel: rgba(4, 12, 27, 0.72);
  --xh-border: rgba(125, 211, 252, 0.18);
}
```

## 5. 左侧星云视觉要求

必须满足：

- 左侧视觉区域不包含任何文字。
- 不显示 `XINGHUAN`、`STELLAR CANVAS`、`星幻`、说明标签或开发描述。
- 视觉要轻，不要做成密集星图或复杂网络节点。
- 有伪 3D 深度：远景星点、近景薄雾、柔和中心光源、层叠半透明结构。
- 有轻微动效：慢速漂移、呼吸、光晕变化即可。
- 鼠标跟随可以影响背景光晕，但不要让粒子追着鼠标乱跑。

推荐视觉构成：

- 远景：非常弱的深色径向渐变 + 稀疏星点。
- 中景：1 到 2 条半透明星云雾带，像被透视压缩的椭圆云层，形成微缩星系星图。
- 前景：少量高亮星点，大小有差异，制造距离感。
- 空间感：使用 `perspective`、`transform-style: preserve-3d`、`rotateX`、`translateZ` 或等价的 CSS 层叠方式。
- 边缘：视觉自然淡出，不要出现硬矩形边界。
- 鼠标跟随：只驱动背景光晕、星云层视差和卡片极轻微倾斜，不能做强烈追踪粒子。

避免：

- 不要做网格线过密的背景。
- 不要做大量斜线交叉。
- 不要做星座连线图。
- 不要做中心发光 logo。
- 不要做旋转很快的轨道。
- 不要像素材网站的“科技背景图”。
- 不要使用外链背景图或依赖远程图片资源，优先用 CSS 渐变、伪元素和少量 DOM 星点生成。

## 6. 右侧登录卡片要求

内容保留：

- 标题：`进入创作星域`
- 副标题：`量子星图`
- 字段：`账号邮箱`
- 字段：`访问密钥`
- 按钮：`进入星幻工作区`

视觉：

- 使用磨玻璃面板，但不要过度透明。
- 圆角建议 `24px` 到 `34px`，不要太硬，也不要像营销卡片过圆。
- 输入框必须是深色嵌入式背景，不采用设计稿截图里的大面积白色输入框。
- 焦点使用青蓝 / 青绿柔和外发光，错误态使用低饱和红色且只出现在表单内。
- 按钮可使用青蓝到青绿渐变，亮面克制。
- 登录卡片要比背景更清晰，确保可读性。
- 卡片内可以保留“星幻画布”品牌名，但不能在左侧星云区重复出现品牌标识。
- 不保留 `SSO 接入`、`组织网络`、找回密钥、版权版本号等当前不可用或容易误导的占位入口。

交互：

- 输入框 focus 有柔和边框和光晕。
- 按钮 hover 轻微上浮或亮度变化。
- 登录 loading 保持原行为。
- 错误提示位置保持在表单内，不打断整体布局。

## 7. 启动页与过渡动画

入口体验包含两个状态：

- 未登录：展示登录首页，用户完成账号密码输入。
- 已登录但工作区尚在加载：展示短暂过渡动画，承接登录页星云视觉，不再显示原 T8 或旧项目页面。

过渡动画要求：

- 视觉延续登录页的深空黑蓝、青绿、青蓝和轻量星云体系。
- 可以有中心抽象光核、细线轨道或进度条，但不能出现中心 logo、营销标识、坐标、延迟、开发版本、调试文字。
- 状态文字最多保留 1 行主状态 + 1 行辅助状态，例如 `正在初始化星图`、`正在载入创作工作区`。
- 总时长建议 `1.2s` 到 `2.4s`，不要固定等待 `4.5s`；真实加载完成应立即进入画布。
- 不做纯白闪屏，避免 `_1/code.html` 里白色爆发造成视觉割裂。
- `prefers-reduced-motion: reduce` 时应直接显示静态 loading 或快速进入工作区。

## 8. 动效与性能要求

动效方向：

- 页面进入时，左侧星云和右侧卡片可做轻微错位入场。
- 星云层慢速漂移，周期建议 12 到 24 秒。
- 鼠标跟随光晕响应要柔和，延迟感可以略明显。
- 卡片 3D tilt 的角度必须克制，建议不超过 `6deg` 到 `8deg`，避免廉价游戏 UI 感。

性能边界：

- 不使用大型 WebGL 库，除非确认 bundle 可控。
- 优先用 CSS 渐变、伪元素、少量 DOM 层和 transform 实现。
- 动画只改 `transform`、`opacity`、`filter` 等相对安全属性。
- 必须提供 `prefers-reduced-motion: reduce` 兜底，关闭大部分动画。

实现边界：

- 不使用 Tailwind CDN、Google Fonts CDN 或远程图片 URL，必须适配现有 React/Vite 项目构建方式。
- 不改变现有认证 API、默认账号预填、错误处理和登录成功回调。
- 不引入额外路由或不可用入口。

## 9. 验收标准

功能验收：

- 未登录时显示入口页，登录 API 行为不变。
- 账号邮箱默认值如现有实现保持不变。
- 右侧登录表单可输入、可提交、错误态可显示。
- 移动端无横向滚动。
- 已登录加载工作区时不再出现 T8 原页面或旧空态。

视觉验收：

- 左侧没有任何文字、logo 或标签。
- 页面第一眼不是“模板科技背景”。
- 星云有轻微深度，但不压过登录卡片。
- 整体仍是黑蓝 / 黑绿 / 青绿科技风。
- 没有紫色主导、没有大面积高亮、没有廉价霓虹。
- 输入框不是白底，登录卡片与背景属于同一套深色科技系统。

代码验收：

- 保留现有登录组件业务逻辑。
- 不引入秘密、账号密码或 API Key。
- 不使用绝对路径。
- 不影响画布页、后台页和节点系统。
- 通过现有入口 UI 验证脚本、Web type-check 和 Web build。
