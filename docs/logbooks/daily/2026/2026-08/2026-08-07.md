# 2026-08-07

## 权限读取与公共资源可迁移性

- `/api/me/permissions` 改为只读取现有授权快照，不再在普通用户请求内触发权限主体 reconciliation 写入。
- 单个节点授权解析异常时按节点失败关闭，并返回 `nodePermissionResolution.status=degraded`，避免整个权限接口变成 500。
- 公共资源媒体使用资源 ID 内容路由；新媒体复制到 `admin/shared-assets/`，历史条目支持按发布者目录物化。
- 新增 `apps/api/dist/cli/shared-resource-assets.js`，迁移前物化历史公共资源并在缺文件时阻断。
- Production 数据迁移包排除 `users/*/output` 和 `users/*/output-archives`，保留公共资源索引、公共资产、用户输入与其他业务数据。

## 只读盘点

- 旧服务器 Production：公共资源 8 条，其中 4 条本地媒体可物化、4 条非本地媒体/工作流引用，无缺失源文件。
- 旧服务器 Gray：公共资源 1 条，为非本地媒体/工作流引用，无缺失源文件。
- 指定成员账号在旧服务器 Production 和 Gray 的 `/api/me/permissions` 当前均返回 200，拒绝节点数为 0；本轮属于去除潜在写入耦合和防止再次出现 500 的加固。
