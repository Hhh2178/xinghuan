## 2026-06-26

### 共享资源库与干净工作流导出第一批收口

目标:
- 让工作流保存/导出/输出统一生成干净模板，避免旧会话、旧任务结果和轮询态混入资源工作流。
- 为公共资源库建立前后端基础链路，支持前台双库浏览、管理员首批上传、普通用户另存为个人资源。
- 让生成库的卡片与完整预览开始向资源库交互壳统一，减少两套重复 UI 逻辑。

变更:
- 新增 `apps/web/src/utils/workflowRuntimeCleanup.ts`，统一剥离工作流模板中的节点运行态字段。
- `apps/web/src/utils/workflowResource.ts` 改为在资源工作流 manifest 生成时清理运行态，同时保留资源索引相关字段。
- 前台新增 `apps/web/src/services/sharedResourceApi.ts`，避免把共享资源接口继续堆进主 `api.ts`。
- `apps/web/src/components/ResourceLibraryDrawer.tsx` 增加 `我的资源库 / 公共资源库` 双源浏览、管理员首批上传入口、公共资源另存为个人资源。
- 生成库抽屉和完整预览开始复用 `ResourceMediaCard`、`ResourcePreviewOverlay`。
- 后端从 `apps/api/src/server.ts` 下沉共享资源路由到 `apps/api/src/shared-resource-routes.ts`，避免继续把分类、条目、复制逻辑堆进热点主文件。

验证:
- `npm run type-check -w @xinghuan/api`
- `npm run type-check -w @xinghuan/web`
- `npm run verify:clean-workflow-export`
- `node scripts/verify-shared-resource-library-contract.mjs`
- `node scripts/verify-generation-library-preview-contract.mjs`
- `node scripts/verify-generation-library-resource-card-contract.mjs`
- `node scripts/verify-generation-library-and-admin-assistant-layout.mjs`
- `npx tsx scripts/verify-workflow-resource-resolver-contract.ts`

影响:
- 保存到资源库的工作流更接近“模板”，不会把旧运行结果继续带入新会话。
- 公共资源库已经有可用的浏览、复制和管理员首批上传链路，后续可在此基础上继续补齐非媒体类型上传与更细的编辑体验。
- `server.ts` 共享资源相关职责明显减少，后续扩展公共资源时可以优先落在独立 route handler 中。

风险:
- 公共资源库当前上传按钮首批仍以媒体类资源为主，`set / pose / workflow` 的前台上传交互尚未补齐。
- 根 `DEVLOG.md` 当前已有其他未收口改动，本轮先把真实推进记入日台账，后续再按批次统一同步摘要入口。

- 继续检查共享资源引用在更多节点与资源类型上的复用表现。
