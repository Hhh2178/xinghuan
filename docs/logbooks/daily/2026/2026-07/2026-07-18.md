# 2026-07-18

## Generation Artifact Authority Gray Validation

- Gray `v0.7.4` migration and initial runtime validation completed; API, Worker, enforced permission readiness, legacy JSON migration, Worker materialization, content access, idempotent Promotion and promoted-binary protection passed.
- Live verifier drift was fixed: requests now carry same-origin headers, use the paginated task response, provide `taskCapability`, and the two relevant verifiers are included in the release package contract.
- HTTP performance sampling found a release blocker: anonymous `GET /` returned `500` consistently while `GET /api/status` remained healthy.
- Root cause: the new generation artifact route delegation evaluated `currentUser!.id` before confirming that an authenticated user existed or that the request matched an artifact route.
- Candidate fix guards the delegated route with `currentUser` and removes the non-null assertion; a framework contract now prevents anonymous requests from dereferencing the artifact owner.
- Production remains on `v0.7.3` and is explicitly paused until Gray passes expanded functional, concurrency, performance, resource-impact and stability validation.
