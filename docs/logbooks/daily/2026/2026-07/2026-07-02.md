## ComfyUI 共享工作流专用执行链路

目标:
- 不再让 `comfyui-app` 节点复用通用图像代理去“伪装执行”
- 为共享工作流补齐真实后台执行入口：选实例、注入参数、提交 prompt、轮询 history、转存输出
- 让前台、后台、connector 三段链路的职责更清晰

变更:
- `apps/api/src/comfyui-execution.ts`
  - 新增 ComfyUI 执行辅助模块，收口工作流 prompt 注入、实例选择、history 轮询、图片上传和结果解析
- `apps/api/src/comfyui-public-routes.ts`
  - 新增 `POST /api/comfyui/apps/:workflowId/run`
  - 支持共享工作流专用执行，不再只提供 catalog
- `apps/api/src/server.ts`
  - ComfyUI 公共路由新增结果转存与输入 URL 归一化依赖
- `apps/web/src/services/comfyuiApps.ts`
  - 运行共享工作流时改走 `/api/comfyui/apps/:workflowId/run`
- `scripts/verify-comfyui-execution-helpers.ts`
  - 新增执行辅助逻辑测试
- `scripts/verify-comfyui-instance-pool-contract.mjs`
  - 新增专用执行入口护栏
- `docs/systems/api/interface-map.md`
- `docs/systems/providers/protocol-layering.md`
- `docs/systems/canvas/node-and-data-model.md`
  - 同步补齐专用执行链路说明

验证:
- `npx tsx scripts/verify-comfyui-execution-helpers.ts`
- `node scripts/verify-comfyui-instance-pool-contract.mjs`
- `npm run type-check -w @xinghuan/api`
- `npm run type-check -w @xinghuan/web`

影响:
- `comfyui-app` 节点开始拥有自己的后台执行入口，不再借通用 provider 图像接口绕路

- 这轮还没有做灰度部署与真实机器实跑

下一步:
- 用一条真实共享工作流在灰度环境做端到端实跑
- 如需支持更多 ComfyUI 文件型输入，再继续补视频/音频上传适配
