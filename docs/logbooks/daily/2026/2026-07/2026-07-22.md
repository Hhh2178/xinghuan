## Canvas Agent 视频理解传输决策

- 确认不采用 FFmpeg 作为 Agent 视频理解前置依赖。Gemini 等具备原生完整视频理解能力的模型优先使用 Provider File 上传；Gemini Files API 的 `fileUri` 是 Provider 临时文件，并非本项目对外 URL。
- 当前有效回退仍为 Artifact 已有的 owner-scoped 时间戳帧。面向明确支持主动拉取的其他 Provider，短期受控 `remote_url` 保留为后续传输能力，默认关闭，不能把内部鉴权 URL、浏览器 URL 或 Agent 任意给出的 URL 交给 Provider。
- 将来启用 `remote_url` 前，必须先交付独立媒体访问网关和单产物短期签名、传输上限、审计快照及撤销策略；该决策不改变现有代码路径、Gray、Production 或 GitHub 状态。
