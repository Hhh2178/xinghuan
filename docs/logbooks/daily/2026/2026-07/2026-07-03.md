## ComfyUI 后台实例池管理界面重构完成

目标:
- 重构 ComfyUI 后台管理界面，采用仪表盘 + 详情页架构
- 实现实例连接测试功能，支持延迟检测、GPU/VRAM 监控、队列状态查询
- 补齐服务端环境变量配置和部署文档

变更:
- 新增 `apps/admin/src/admin-comfyui-overview.tsx`：仪表盘概览页，展示所有实例、在线/离线统计、共享工作流数量
- 新增 `apps/admin/src/admin-comfyui-detail.tsx`：实例详情页，支持基本配置、工作流管理、执行日志三个标签页
- 修改 `apps/admin/src/admin-comfyui-instances-panel.tsx`：改为路由组件，在概览页和详情页之间切换
- 新增完整 CSS 样式到 `apps/admin/src/styles.css`：metric-card、instance-grid、instance-card、detail-header、tabs 等
- 新增后端 API `POST /api/admin/comfyui/instances/:id/test-connection` 到 `apps/api/src/comfyui-instance-routes.ts`
- 新增 `testComfyuiConnection()` 和 `fetchComfyuiEndpoint()` 函数，支持并发请求 `/system_stats` 和 `/queue` 端点
- 新增 `config/.env.example` 环境变量：`XINGHUAN_COMFYUI_CONNECTOR_TOKEN`
- 更新 `docs/prd/v0.1.0/progress.md`：记录 ComfyUI 后台重构完成状态

验证:
- 前端组件已通过 TypeScript 类型检查
- 后端 API 逻辑已完成，支持超时控制和错误处理
- CSS 样式已完整添加，包含响应式布局和移动端适配
- 环境变量配置已添加到示例文件

影响:
- ComfyUI 后台管理体验大幅提升：从单页表单改为仪表盘 + 详情页架构
- 管理员可以实时测试实例连接状态、查看 GPU/VRAM 使用情况、监控队列任务数
- 实例健康状态可视化：在线/降级/离线三种状态，带颜色指示器
- 工作流管理更清晰：每个实例独立管理工作流草稿，可推送到共享区
- 部署更简单：服务端只需配置 `XINGHUAN_COMFYUI_CONNECTOR_TOKEN`，机器侧 connector 自动注册和心跳

风险:
- 当前仅完成前端和 API 实现，尚未进行浏览器真实测试
- 连接测试功能依赖 ComfyUI 实例的 `/system_stats` 和 `/queue` 端点，需要 ComfyUI 版本支持
- 机器侧 connector 需要正确配置环境变量才能连接服务器

## ComfyUI 图标一致性修复与 connector harness 灰度激活

目标:
- 修复用户反馈的 ComfyUI 相关后台图标风格不统一（"图标比较乱"）问题
- 排查并修复灰度环境无法接入本机 ComfyUI 实例的问题
- 帮助用户把本机 ComfyUI 实例接入灰度后台

根因 1（图标不统一）:
- `apps/admin/src/styles.css` 中本轮新增的 ComfyUI 相关按钮统一使用了 `border-radius: 6px`，
  与全站按钮设计规范（`.admin-sidebar button` / `.icon-button` / `.form-grid button` 等均为 `8px`）不一致
- `.admin-comfyui-instance-card__footer button svg` 图标尺寸为 `14px`，
  与同页面其余按钮（`16px`）和全站按钮图标规范不一致
- 更严重的问题：本轮新增的 `.error-banner` 规则（用于 ComfyUI 概览页消息条）与
  `apps/admin/src/styles.css:2949` 处早已存在的全局 `.error-banner` 选择器同名冲突，
  CSS 级联顺序导致后定义的样式（圆角、内边距、颜色）覆盖了全站所有使用 `error-banner`
  的组件（`main.tsx`、`admin-generation-library-panel.tsx`、`admin-public-resources-panel.tsx`、
  `admin-runninghub-workspace.tsx` 等），这是本次视觉不一致最主要的成因

变更 1:
- 删除重复/冲突的 `.error-banner` 规则，恢复使用全局既有定义
- 统一本轮新增 ComfyUI 相关按钮圆角为 `8px`（`admin-comfyui-band__actions button`、
  `admin-comfyui-instance-card__footer button`、`back-button`、
  `admin-comfyui-detail-header__actions button`、`admin-comfyui-actions button`、
  `message-banner`、`empty-state button` 等）
- 统一 `admin-comfyui-instance-card__footer button svg` 图标尺寸为 `16px`

根因 2（灰度无法接入本机实例）:
