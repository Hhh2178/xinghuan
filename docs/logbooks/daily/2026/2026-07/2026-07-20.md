## AICOPY SD 混合媒体协议与错误诊断

- 新版 2.0.15 文档确认 SD 视频存在四种请求 profile，旧的顶层 `duration / metadata / images / audios` 契约不能用于按次模型或渠道 431。
- Gray/Production 只读核查确认新增 `sd-720-fast-渠道9:16（按次）` 与 `sd-720-fast-渠道2（按秒）` 复制了旧 SD2 契约；生产相关模型同时关闭了参考视频/音频能力，因此文本生成可成功但素材被遗漏或被上游忽略。
- 画布后台模型分支原先不提交 `videos`，API 校验、队列 payload、Worker Adapter 与 Admin 契约 source 也都缺少参考视频，属于端到端能力缺口。
- Production `2026-07-20 12:33-12:35` 的 `fail_to_fetch_task` 只读审计确认最内层原因是 Prompt 为 4944/5507 UTF-8 字节，超过上游 4096 字节限制；请求在创建 task 前被拒绝，所以服务商后台没有任务记录。
- 修复按 TDD 增加 `videos / media / referenceMode` 契约、四类 SD profile 配置器、参考视频全链路校验与传递、4096 字节入队前校验和嵌套错误解包。
- 用户明确要求本轮发布后不清理旧 Release，后续 Gray/Production 部署不得运行 retention prune。
