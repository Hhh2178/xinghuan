# 画布生成节点费用提示 Gray v0.7.17 发布

- release：`20260721-canvas-node-cost-badge-gray-r1-v0717`
- source commit：`bbdad88`
- archive：`20260721-canvas-node-cost-badge-gray-r1-v0717.tar.gz`
- 回滚：`20260721-admin-cost-accounting-gray-r1-v0715`

## 变更

- 图片、视频、LLM、音频等生成节点左上方增加紧凑金币费用提示，并沿用画布暗色视觉规范。
- 费用预估直接绑定当前节点选择的模型与服务商；切换任一选项后即时重算，不沿用旧模型金额。
- 按次显示单次预计费用；按秒优先结合节点时长显示预计总价，缺少时长时显示每秒单价。
- 任务完成后读取不可变费用快照显示结算金额；任务快照与当前模型不一致时不覆盖当前模型预估。
- 后台未配置或已停用价格时，不显示费用窗口和金币图标。
- 新增所有者隔离的成员任务费用摘要接口；不存在或不属于当前账号的任务不会泄露费用。
