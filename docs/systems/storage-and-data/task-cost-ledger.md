# 任务费用台账

## 权威表

- `xh_model_pricing_versions`：追加式模型价格版本。
- `xh_task_cost_items`：任务费用快照和终态结算记录。

## 生命周期

1. 新任务 INSERT 后，触发器读取任务创建时间生效的价格版本。
2. 同时快照账号、用户组、Provider、模型和请求秒数。
3. 成功/失败/取消终态更新后，只结算仍为 `pending` 的费用项。
4. 结算完成后重复终态更新不改写已结算金额。

## 计费规则

- 成功：计费。
- 失败：不计费。
- 取消且上游确认取消成功：不计费。
- 本地取消、没有上游取消端口/任务 ID/Key、上游取消失败：计费。
- 按秒：上游 billed seconds → 输出时长 → 请求时长，正数向上取整。
- 缺少价格或按秒缺少任何可用时长：`unpriced`。

## 历史和金额

- Migration 025 不回填旧任务。
- 费用分析通过“任务无费用项”和费用项 `unpriced` 共同展示未定价数量。
- 金额使用 PostgreSQL `numeric(20,6)`；API 以小数字符串传输。
