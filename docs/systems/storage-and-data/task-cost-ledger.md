# 任务费用台账

## 权威表

- `xh_model_pricing_versions`：追加式模型价格版本。
- `xh_task_cost_items`：任务费用快照和终态结算记录。

## 生命周期

1. 新任务 INSERT 后，触发器读取任务创建时间生效的价格版本。
2. 同时快照账号、用户组、Provider、模型和请求秒数。
3. 成功/失败/取消终态更新后，只结算仍为 `pending` 的费用项。
4. 结算完成后重复终态更新不改写已结算金额。

## 计费规则

- 成功：计费。
- 失败：不计费。
- 取消且上游确认取消成功：不计费。
- 本地取消、没有上游取消端口/任务 ID/Key、上游取消失败：计费。
- 按秒：上游 billed seconds → 输出时长 → 请求时长，正数向上取整。
- 按次：默认每个任务计 `1` 次；由 Worker 管理的批量生成任务以成功结果中的 `providerRequestCount` 结算实际 Provider 请求次数，未提供该字段的既有任务保持 `1` 次口径。
- 缺少价格或按秒缺少任何可用时长：`unpriced`。

## 历史和金额

- Migration 025 不回填旧任务。
- 费用分析通过“任务无费用项”和费用项 `unpriced` 共同展示未定价数量。
- 金额使用 PostgreSQL `numeric(20,6)`；API 以小数字符串传输。

## 画布费用展示

- 执行前报价来自当前用户有权查看的模型目录价格摘要，只表达当前选择的计费口径。
- 模型或 Provider 切换会立即切换报价，但不会改写任何既有任务费用项。
- 执行后金额通过 owner-scoped 批量接口读取 `xh_task_cost_items`；服务端使用任务表 owner 再校验，不能跨账号读取。
- 没有 `pricing_version_id` 的费用项不向画布展示费用窗口；有价格快照但缺少按秒数量时展示待核算状态。
- 批量金额继续使用六位十进制定点相加，多币种分别返回，不做换算。
