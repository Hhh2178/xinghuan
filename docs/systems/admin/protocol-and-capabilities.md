# Admin 协议与能力边界

## 当前高频后台能力

- Provider 与模型治理
- RunningHub 条目治理
- 系统并发与运行态观测
- 环境同步
- 用户、会话、任务、审计查看

## RunningHub 后台能力

- 新建 / 删除 / 另存为 / 启停
- 测试条目
- AI 分析并填写
- 同步输入槽
- 输出定义与执行规则编辑

## 系统页能力

- 修改并发设置
- 查看按类别并发
- 查看实际生效并发
- 查看 Worker 数与槽位数
- 查看 RH 平台窗口

## 边界说明

- Hermes 接入的 AI 分析和 RH 工作台里的辅助分析不是同一套外部接入
- RH 的当前分析能力以本项目内代码推断为主，再结合样例结构生成草案
