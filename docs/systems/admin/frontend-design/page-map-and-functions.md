# 页面地图与功能记录

本文件记录 Admin 新后台 UI 的页面地图、每个页面的作用和核心功能。后续新增后台功能时，应优先判断放入哪个工作域和哪个页面，避免继续平铺增加菜单。

## 0. 当前落地状态

### 2026-07-17：十域路由化与页面职责拆分

已落地：

- 一级导航由五域升级为十域，`RH 管理` 与 `ComfyUI 管理` 独立。
- 账号/用户组/会话/权限、Provider/模型、RH 工作流/应用/Key 池、用量/审计、系统健康/运行参数/环境同步均有稳定 URL。
- ComfyUI 实例详情的配置、工作流、日志子视图支持深链。
- 页面业务数据按域加载，页面组件使用动态 import，首屏主包由约 534 kB 降为约 261 kB（未压缩构建产物口径）。
- 工作区级错误边界保证单页渲染失败不会拖垮整个后台。
- 页面导航、焦点态、动效时长和 `prefers-reduced-motion` 统一由壳层与 Token 管理。

约束：

- 内容域不重新暴露已退役的“生成库”入口。
- ComfyUI 当前处于开发冻结期，本批只做既有实例/工作流页面的路由重组，不新增业务协议。
- 发布、回滚继续由项目 Harness 与受控 release entrypoint 执行，Admin 前端不伪造不存在的发布 API。

### 2026-06-27 Phase 1：Starlight Shell 骨架

已落地：

- 后台 Shell 采用 `starlight-shell` 视觉骨架。
- 左侧导航已从旧的平铺页面入口切换为五大工作域：
  - 运营总览
  - 能力配置
  - 资源与内容
  - 组织与治理
  - 系统与发布
- 现有旧后台页面已映射进五大工作域，业务面板暂不移除。
- 顶部状态栏展示当前工作域、当前页面、刷新策略和最近刷新时间。
- 页面内容区增加 `Suspense` 加载边界，作为后续懒加载拆分基础。
- 每个工作域顶部增加二级页面入口卡，保留旧页面功能的可达性。

本阶段未完成：

- 业务页面内部还未全部重画成 stitch 风格。
- 公共资源卡片、权限矩阵、模型目录、RH 条目、任务详情等细节页面仍需后续分批改造。
- 真正的组件级代码分包和按页面 dynamic import 还在后续批次。

### 2026-06-27 Phase 2：公共资源管理卡片工作区

已落地：

- 公共资源管理页接入 `admin-public-resources-page--starlight` 页面皮肤。
- 页面顶部增加资源概览 Inspector 条，展示当前类型、当前分类、资源数量和已归类数量。
- 分类侧栏接入 `admin-public-resources-sidebar--starlight`，分类名称使用白色高对比文本并允许长文本安全换行。
- 资源卡片接入 `admin-public-resource-card--starlight`，采用上预览、下参数与管理的上下结构。
- 桌面资源网格优先一行 4 个卡片，中等宽度降为 3 个，移动端降为 1 个。
- 图片、视频、音频预览统一进入黑底 `contain` 舞台，保持完整素材比例，不裁切主体。
- 卡片操作按钮抽象为可换行 action row，避免后续增加动作时再次溢出。
- 完整预览弹窗接入 `admin-media-preview-modal--starlight`，继续支持图片、视频、音频完整查看。

本阶段未完成：

- 公共资源权限摘要、按组开放范围、批量授权仍在后续权限矩阵批次。
- 资源详情 Inspector 仍为卡片内编辑，后续可升级为右侧详情抽屉。
- 资源大批量操作、批量归类、批量删除、导入结果报告待后续批次。

### 2026-06-27 Phase 3：组织与治理工作区第二阶段

已落地：

- `组织与治理` 顶部加入治理概览条，展示账号总数、普通成员、管理员、未分组账号和活跃会话。
- `组织与治理` 进入后先展示 `users-governance-overview` 总览首页，提供域级说明和到账号 / 分组 / 权限 / 会话 / 审计的快速下钻入口。
- `用户组` 工作区接入 `users-group-workbench--starlight`，形成左侧创建轨道、右侧工作台和顶部概览条的稳定结构。
- `账号管理` 工作区接入 `users-accounts-workbench--starlight`，形成左侧创建轨道、右侧治理摘要卡与账号表治理台的稳定结构。
- `会话管理` 工作区接入 `users-sessions-workbench--starlight`，补齐会话概览条、状态提示卡和会话检查工具条。
- `成功用量驾驶舱` 补入治理摘要条和 overview 面板，先给出 Top 分组、Top 模型、Top RH 条目和统计口径，再进入图表与矩阵。
- 用户组卡片新增独立 summary 区和 action row，成员提示、限制摘要、编辑输入和操作按钮层级更清晰。
- `权限策略` 工作区接入 `permissions-shell--starlight`，补充顶部影响面板，强化“当前筛选条目 / 已限制项 / 缺失限制项”的治理视角。
- 权限页左侧分组轨道继续保留，但视觉强调进一步降低，主视觉重新回到右侧编辑器。
- 权限页补入 section overview，用于先解释当前权限域的作用、前台隐藏效果和本次批量操作的影响范围。
- RH 应用、RH 工作流、节点能力权限卡片补齐稳定元信息区，长 catalogId / runTargetId / nodeType id 进入独立信息块展示。
- 公共资源分类与条目在空筛选状态下补齐明确 empty state，避免被误判为加载异常。
- 账号表和会话表补齐 table toolbar，用于说明巡检重点和治理动作范围，不再把说明文案硬塞进表格正文流。
- 用量驾驶舱在 KPI 之上新增治理摘要条，在图表区之前新增 overview 面板，避免管理员直接掉进“只看图不知重点”的状态。
- 分组名、组说明、节点 ID、catalogId 等长文本继续强化防溢出规则，按钮区继续遵循真实换行。

本阶段未完成：

- `账号管理` 仍缺少完整 Inspector 与更深的批量治理视图。
- `会话管理` 已进入治理工作台结构，但仍缺少更强的风控摘要与筛选器。
- `用量分析` 已进入新的治理工作台语言，但仍缺少筛选器和更完整的首页承接关系。
- `组织与治理` 首页尚未单独抽成完整工作域首页。
- `组织与治理` 首页已落地为总览首页，但后续仍可继续补筛选器、异常告警和最近变更列表。

## 1. 一级工作域

新版 Admin 后台分为十个一级工作域：

1. 运营总览
2. 账号与组织
3. 权限与安全
4. Provider 与模型
5. RH 管理
6. ComfyUI 管理
7. 内容与资源
8. 任务与运行
9. 数据分析与审计
10. 系统与发布

## 2. 全局页面与组件

### 后台 Shell

作用：

- 承载整个后台。
- 提供导航、环境状态、全局搜索、告警、AI 助手和管理员操作。

功能：

- 左侧一级导航。
- 顶部状态栏。
- 主工作区。
- 右侧 AI 助手。
- 全局弹窗。
- 全局提示。

### 全局搜索

作用：

- 跨后台搜索对象并跳转详情。

搜索对象：

- 用户、用户组。
- Provider、模型。
- RH AI 应用、RH 工作流。
- 公共资源、分类、标签。
- 任务。
- 审计 requestId。
- 公告。

### 告警中心

作用：

- 集中展示系统和业务风险。

告警来源：

- 任务失败趋势。
- 队列积压。
- Provider 探测失败。
- 模型测试失败。
- RH Key 池异常。
- 数据库 / Redis / Worker 异常。
- requestId 覆盖率不足。
- revision 冲突。
- 环境同步冲突。

## 3. 运营总览

### 运营总览首页

作用：

- 后台第一屏。
- 快速判断平台是否健康、任务是否积压、能力使用是否异常。

功能区：

- 环境健康条。
- 核心 KPI。
- 成功用量趋势。
- 能力占比。
- 队列运行状态。
- 风险和待处理。
- 最近变更。

下钻：

- KPI 下钻到任务、模型、资源、用户、系统健康等页面。
- 风险下钻到告警中心或对应对象。

## 4. 能力配置

### 能力配置首页

作用：

- 展示所有可被画布使用的生成和智能能力。

功能：

- Provider 摘要。
- 模型摘要。
- RH AI 应用摘要。
- RH 工作流摘要。
- RH Key 池摘要。
- 节点能力摘要。
- AI 助手接入摘要。

### Provider 管理

作用：

- 管理模型服务商接入。

功能：

- 新增、编辑、删除 Provider。
- 配置 Base URL、协议、API Key、备注。
- 验证地址。
- 拉取模型。
- AI 协助配置。
- 查看关联模型和 RH 条目。

### 模型目录

作用：

- 管理所有 Provider 下的模型。

功能：

- 按 Provider、能力、启用状态筛选。
- 手动新增模型。
- 导入拉取模型。
- 编辑模型能力、能力标签、输入能力、参数 schema、高级配置。
- 测试模型。
- 启用、停用、删除模型。
- 查看用量摘要和权限摘要。

### RH AI 应用

作用：

- 管理 RunningHub AI 应用目录。

功能：

- 新建、编辑、复制、删除、启停 AI 应用。
- 配置基础信息、输入槽、参数 schema、输出定义、执行规则。
- 测试运行。
- AI 分析并填写。
- 查看权限和用量摘要。

### RH 工作流

作用：

- 管理 RunningHub workflow 条目。

功能：

- 新建、编辑、复制、删除、启停工作流。
- 显示 workflowId、runTargetId、nodeInfoList 状态。
- 支持显式无入参工作流。
- 阻止 app / workflow 混合态。

### RH Key 池

作用：

- 管理 RunningHub Key 和平台并发窗口。

功能：

- 新增、编辑、删除 Key。
- 设置默认 Key。
- 设置单 Key 最大并发。
- 启用、停用 Key。
- 自动汇总 RH 平台总并发。
- 查看当前占用。

### 节点能力目录

作用：

- 管理节点能力可见性与权限关系。

功能：

- 查看节点 ID、名称、组、输入输出类型、依赖模型、依赖资源。
- 查看哪些用户组禁用节点。
- 跳转权限策略。

### AI 助手配置

作用：

- 管理创作侧和后台侧 AI 助手。

功能：

- 创作侧助手配置。
- 后台助手配置。
- 外部服务接入配置。
- Hermes / fallback。
- 默认模型、profile、workspace。
- 上下文读取权限。

## 5. 资源与内容

### 资源与内容首页

作用：

- 展示平台内容资产总览。

功能：

- 公共资源总量。
- 图像 / 视频 / 音频 / 素材集 / 姿势 / 工作流分布。
- 最近上传、最近编辑。
- 权限限制最多的分类。
- 公告状态摘要。

### 公共资源管理

作用：

- 管理平台公共素材。

功能：

- 类型切换。
- 分类管理。
- 上传本地资源。
- 搜索。
- 卡片网格。
- 完整预览。
- 编辑标题、分类、标签、备注。
- 删除资源。
- 查看权限摘要。

交互规则：

- 默认以卡片网格呈现，不使用旧表格作为主视图。
- 卡片上半区只负责素材完整预览，黑底补边，不拉伸、不裁切。
- 卡片下半区负责标题、分类、标签、备注、文件信息和操作。
- 卡片操作区必须允许自动换行，新增按钮不能造成横向溢出。
- 分类侧栏不能形成过小滚动陷阱，分类名称必须高对比可读。

### 生成库后台治理

作用：

- 从后台治理全平台生成结果。

功能：

- 按账号、组、能力、Provider、模型、时间筛选。
- 预览图片、视频、音频。
- 查看任务来源、payload、result、参数摘要。
- 标记、归档、删除、转公共资源。

当前前端落地补记：

- 后台已接入 `生成库` 分页入口，位于 `资源与内容` 工作域中，和 `公共资源 / 公告` 并列。
- 当前先复用现有生成库链路，以卡片工作台治理当前账号生成库结果。
- 采用与公共资源一致的完整预览规则：
  - 卡片预览黑底补边
  - 图片 / 视频 / 音频都优先完整显示
  - 预览弹层继续使用 `contain`
- 卡片下半区负责展示：
  - 任务来源
  - Provider / 模型
  - 剩余保留时间
  - 转公共资源 / 删除

### 公告中心

作用：

- 创建、编辑、发布公告。

功能：

- 草稿、发布、归档、删除。
- 置顶、强提醒、前台弹窗。
- 范围、发布时间、下线时间、版本号。
- 发布确认。

### 分类与标签

作用：

- 统一管理资源和内容分类标签。

功能：

- 新建、重命名、合并、废弃标签。
- 查看标签资源数和最近使用。

## 6. 组织与治理

### 组织与治理首页

作用：

- 展示账号、组、权限、会话、用量和审计概况。

功能：

- 账号总数、启用账号、管理员、用户组、活跃会话。
- 今日成功调用。
- Top 用户组、Top 账号。
- 最近权限变更。

### 账号管理

作用：

- 管理用户账号。

功能：

- 创建账号。
- 编辑名称、角色、组、备注。
- 启用、禁用。
- 重置密码。
- 查看会话、用量、审计、权限摘要。

### 用户组管理

作用：

- 管理组织分组。

功能：

- 新建、编辑、删除分组。
- 查看成员数量。
- 查看权限限制数。
- 查看用量摘要。
- 跳转权限配置。

交互规则：

- 默认使用左侧创建轨道 + 右侧卡片工作台，不退回到窄列滚动表单。
- 卡片需要同时表达成员数、限制摘要、可编辑字段和删除约束。
- 删除受成员占用影响时，提示必须清晰可见，不能只放在 tooltip 内。

### 权限策略

作用：

- 按用户组控制普通用户可见资源和能力。

功能：

- 公共资源分类权限。
- 公共资源条目权限。
- RH AI 应用权限。
- RH 工作流权限。
- 节点能力权限。
- 批量允许、批量禁用。
- 影响预览。
- 保存条。

前台效果：

- 无权限内容直接隐藏。

交互规则：

- 左侧分组 rail 负责切换，不承担主视觉中心。
- 顶部摘要条和影响面板必须先帮助管理员判断“当前组限制了多少内容”。
- 允许态、禁用态、选中态颜色必须明确分离，避免误判。
- 缺失限制项必须可见，不允许因为目录暂时缺失而静默丢失。

### 会话管理

作用：

- 管理登录会话。

功能：

- 查看活跃 / 已撤销 / 已过期会话。
- 查看 IP、User-Agent、创建时间、最后访问、过期时间。
- 强制下线。

### 用量分析

作用：

- 查看成功任务统计。

口径：

- 只统计 `succeeded`。
- 图像、视频、LLM、音频按模型统计。
- RH 按 AI 应用或工作流条目统计。
- 删除账号保留历史用量。

功能：

- KPI 条带。
- 能力占比。
- 分组排行。
- 账号排行。
- 每日趋势。
- 模型矩阵。
- RH 条目矩阵。

### 审计日志

作用：

- 记录后台关键操作。

功能：

- 按时间、操作者、动作、对象、requestId、IP 筛选。
- 查看 User-Agent 和摘要。
- 跳转对象详情。

功能：

- 数据库。
- Redis。

- 队列。
- 任务健康。
- 审计健康。

作用：

功能：

作用：

- gray 和 production 数据差异预览与同步。

当前对象：

- Provider。
- Provider 下模型。
