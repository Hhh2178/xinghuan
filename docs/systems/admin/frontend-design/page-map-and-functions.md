# 页面地图与功能记录

本文件记录 Admin 新后台 UI 的页面地图、每个页面的作用和核心功能。后续新增后台功能时，应优先判断放入哪个工作域和哪个页面，避免继续平铺增加菜单。

## 0. 当前落地状态

### 2026-06-27 Phase 1：Starlight Shell 骨架

已落地：

- 后台 Shell 采用 `starlight-shell` 视觉骨架。
- 左侧导航已从旧的平铺页面入口切换为五大工作域：
  - 运营总览
  - 能力配置
  - 资源与内容
  - 组织与治理
  - 系统与发布
- 现有旧后台页面已映射进五大工作域，业务面板暂不移除。
- 顶部状态栏展示当前工作域、当前页面、刷新策略和最近刷新时间。
- 页面内容区增加 `Suspense` 加载边界，作为后续懒加载拆分基础。
- 每个工作域顶部增加二级页面入口卡，保留旧页面功能的可达性。

本阶段未完成：

- 业务页面内部还未全部重画成 stitch 风格。
- 公共资源卡片、权限矩阵、模型目录、RH 条目、任务详情等细节页面仍需后续分批改造。
- 真正的组件级代码分包和按页面 dynamic import 还在后续批次。

### 2026-06-27 Phase 2：公共资源管理卡片工作区

已落地：

- 公共资源管理页接入 `admin-public-resources-page--starlight` 页面皮肤。
- 页面顶部增加资源概览 Inspector 条，展示当前类型、当前分类、资源数量和已归类数量。
- 分类侧栏接入 `admin-public-resources-sidebar--starlight`，分类名称使用白色高对比文本并允许长文本安全换行。
- 资源卡片接入 `admin-public-resource-card--starlight`，采用上预览、下参数与管理的上下结构。
- 桌面资源网格优先一行 4 个卡片，中等宽度降为 3 个，移动端降为 1 个。
- 图片、视频、音频预览统一进入黑底 `contain` 舞台，保持完整素材比例，不裁切主体。
- 卡片操作按钮抽象为可换行 action row，避免后续增加动作时再次溢出。
- 完整预览弹窗接入 `admin-media-preview-modal--starlight`，继续支持图片、视频、音频完整查看。

本阶段未完成：

- 公共资源权限摘要、按组开放范围、批量授权仍在后续权限矩阵批次。
- 资源详情 Inspector 仍为卡片内编辑，后续可升级为右侧详情抽屉。
- 资源大批量操作、批量归类、批量删除、导入结果报告待后续批次。

## 1. 一级工作域

新版 Admin 后台分为五个一级工作域：

1. 运营总览
2. 能力配置
3. 资源与内容
4. 组织与治理
5. 系统与发布

## 2. 全局页面与组件

### 后台 Shell

作用：

- 承载整个后台。
- 提供导航、环境状态、全局搜索、告警、AI 助手和管理员操作。

功能：

- 左侧一级导航。
- 顶部状态栏。
- 主工作区。
- 右侧 AI 助手。
- 全局弹窗。
- 全局提示。

### 全局搜索

作用：

- 跨后台搜索对象并跳转详情。

搜索对象：

- 用户、用户组。
- Provider、模型。
- RH AI 应用、RH 工作流。
- 公共资源、分类、标签。
- 任务。
- 审计 requestId。
- 公告。

### 告警中心

作用：

- 集中展示系统和业务风险。

告警来源：

- 任务失败趋势。
- 队列积压。
- Provider 探测失败。
- 模型测试失败。
- RH Key 池异常。
- 数据库 / Redis / Worker 异常。
- requestId 覆盖率不足。
- revision 冲突。
- 环境同步冲突。

## 3. 运营总览

### 运营总览首页

作用：

- 后台第一屏。
- 快速判断平台是否健康、任务是否积压、能力使用是否异常。

功能区：

- 环境健康条。
- 核心 KPI。
- 成功用量趋势。
- 能力占比。
- 队列运行状态。
- 风险和待处理。
- 最近变更。

下钻：

- KPI 下钻到任务、模型、资源、用户、系统健康等页面。
- 风险下钻到告警中心或对应对象。

## 4. 能力配置

### 能力配置首页

作用：

- 展示所有可被画布使用的生成和智能能力。

功能：

- Provider 摘要。
- 模型摘要。
- RH AI 应用摘要。
- RH 工作流摘要。
- RH Key 池摘要。
- 节点能力摘要。
- AI 助手接入摘要。

### Provider 管理

作用：

- 管理模型服务商接入。

功能：

- 新增、编辑、删除 Provider。
- 配置 Base URL、协议、API Key、备注。
- 验证地址。
- 拉取模型。
- AI 协助配置。
- 查看关联模型和 RH 条目。

### 模型目录

作用：

- 管理所有 Provider 下的模型。

功能：

- 按 Provider、能力、启用状态筛选。
- 手动新增模型。
- 导入拉取模型。
- 编辑模型能力、能力标签、输入能力、参数 schema、高级配置。
- 测试模型。
- 启用、停用、删除模型。
- 查看用量摘要和权限摘要。

### RH AI 应用

作用：

- 管理 RunningHub AI 应用目录。

功能：

- 新建、编辑、复制、删除、启停 AI 应用。
- 配置基础信息、输入槽、参数 schema、输出定义、执行规则。
- 测试运行。
- AI 分析并填写。
- 查看权限和用量摘要。

### RH 工作流

作用：

- 管理 RunningHub workflow 条目。

功能：

- 新建、编辑、复制、删除、启停工作流。
- 显示 workflowId、runTargetId、nodeInfoList 状态。
- 支持显式无入参工作流。
- 阻止 app / workflow 混合态。

### RH Key 池

作用：

- 管理 RunningHub Key 和平台并发窗口。

功能：

- 新增、编辑、删除 Key。
- 设置默认 Key。
- 设置单 Key 最大并发。
- 启用、停用 Key。
- 自动汇总 RH 平台总并发。
- 查看当前占用。

### 节点能力目录

作用：

- 管理节点能力可见性与权限关系。

功能：

- 查看节点 ID、名称、组、输入输出类型、依赖模型、依赖资源。
- 查看哪些用户组禁用节点。
- 跳转权限策略。

### AI 助手配置

作用：

- 管理创作侧和后台侧 AI 助手。

功能：

- 创作侧助手配置。
- 后台助手配置。
- 外部服务接入配置。
- Hermes / fallback。
- 默认模型、profile、workspace。
- 上下文读取权限。

## 5. 资源与内容

### 资源与内容首页

作用：

- 展示平台内容资产总览。

功能：

- 公共资源总量。
- 图像 / 视频 / 音频 / 素材集 / 姿势 / 工作流分布。
- 最近上传、最近编辑。
- 权限限制最多的分类。
- 公告状态摘要。

### 公共资源管理

作用：

- 管理平台公共素材。

功能：

- 类型切换。
- 分类管理。
- 上传本地资源。
- 搜索。
- 卡片网格。
- 完整预览。
- 编辑标题、分类、标签、备注。
- 删除资源。
- 查看权限摘要。

交互规则：

- 默认以卡片网格呈现，不使用旧表格作为主视图。
- 卡片上半区只负责素材完整预览，黑底补边，不拉伸、不裁切。
- 卡片下半区负责标题、分类、标签、备注、文件信息和操作。
- 卡片操作区必须允许自动换行，新增按钮不能造成横向溢出。
- 分类侧栏不能形成过小滚动陷阱，分类名称必须高对比可读。

### 生成库后台治理

作用：

- 从后台治理全平台生成结果。

功能：

- 按账号、组、能力、Provider、模型、时间筛选。
- 预览图片、视频、音频。
- 查看任务来源、payload、result、参数摘要。
- 标记、归档、删除、转公共资源。

### 公告中心

作用：

- 创建、编辑、发布公告。

功能：

- 草稿、发布、归档、删除。
- 置顶、强提醒、前台弹窗。
- 范围、发布时间、下线时间、版本号。
- 发布确认。

### 分类与标签

作用：

- 统一管理资源和内容分类标签。

功能：

- 新建、重命名、合并、废弃标签。
- 查看标签资源数和最近使用。

## 6. 组织与治理

### 组织与治理首页

作用：

- 展示账号、组、权限、会话、用量和审计概况。

功能：

- 账号总数、启用账号、管理员、用户组、活跃会话。
- 今日成功调用。
- Top 用户组、Top 账号。
- 最近权限变更。

### 账号管理

作用：

- 管理用户账号。

功能：

- 创建账号。
- 编辑名称、角色、组、备注。
- 启用、禁用。
- 重置密码。
- 查看会话、用量、审计、权限摘要。

### 用户组管理

作用：

- 管理组织分组。

功能：

- 新建、编辑、删除分组。
- 查看成员数量。
- 查看权限限制数。
- 查看用量摘要。
- 跳转权限配置。

### 权限策略

作用：

- 按用户组控制普通用户可见资源和能力。

功能：

- 公共资源分类权限。
- 公共资源条目权限。
- RH AI 应用权限。
- RH 工作流权限。
- 节点能力权限。
- 批量允许、批量禁用。
- 影响预览。
- 保存条。

前台效果：

- 无权限内容直接隐藏。

### 会话管理

作用：

- 管理登录会话。

功能：

- 查看活跃 / 已撤销 / 已过期会话。
- 查看 IP、User-Agent、创建时间、最后访问、过期时间。
- 强制下线。

### 用量分析

作用：

- 查看成功任务统计。

口径：

- 只统计 `succeeded`。
- 图像、视频、LLM、音频按模型统计。
- RH 按 AI 应用或工作流条目统计。
- 删除账号保留历史用量。

功能：

- KPI 条带。
- 能力占比。
- 分组排行。
- 账号排行。
- 每日趋势。
- 模型矩阵。
- RH 条目矩阵。

### 审计日志

作用：

- 记录后台关键操作。

功能：

- 按时间、操作者、动作、对象、requestId、IP 筛选。
- 查看 User-Agent 和摘要。
- 跳转对象详情。

## 7. 系统与发布

### 系统与发布首页

作用：

- 展示系统运行、任务队列、环境同步和发布状态。

功能：

- 当前环境和版本。
- API、数据库、Redis、Worker 健康。
- 队列深度。
- 失败趋势。
- requestId 覆盖率。
- revision 冲突。
- 发布状态。

### 系统健康

作用：

- 查看系统健康仪表。

功能：

- 服务与版本。
- 数据库。
- Redis。
- Worker。
- 队列。
- 任务健康。
- 审计健康。
- 冲突健康。
- 告警。
- 存储。

### 运行参数

作用：

- 配置任务并发和 RH 并发治理。

功能：

- 图片 / 视频 / 音频总并发。
- 图片 / 视频 / 音频单用户并发。
- RH 平台并发治理开关。
- 配置值和实际生效值。
- revision 冲突处理。

### 任务队列

作用：

- 查看队列运行和积压。

功能：

- queued / running / succeeded / failed。
- 队列深度。
- 配置并发。
- 实际生效并发。
- Worker 数。
- 槽位数。

### 任务列表

作用：

- 查看、取消、重试任务。

功能：

- 按状态、能力、Provider、模型、账号、组、时间筛选。
- 查看日志、payload、result、失败原因。
- queued / running 可取消。
- failed / cancelled 可重试。

### 环境同步

作用：

- gray 和 production 数据差异预览与同步。

当前对象：

- 用户。
- Provider。
- Provider 下模型。

预留对象：

- RH 条目。
- 公共资源。
- 权限策略。
- 公告。

功能：

- 选择源 / 目标环境。
- 差异预览。
- 冲突决策。
- 勾选同步。
- 确认弹窗。
- 同步结果。

### 发布状态

作用：

- 展示 gray / production release、版本和验证状态。

功能：

- 当前 gray release。
- 当前 production release。
- API status。
- release gate。
- 最近验证。
- 回滚说明入口。

## 8. 新增功能挂载规则

新增 Provider、模型、RH、节点能力：

- 放入能力配置。
- 同步权限目录和用量分析。

新增素材、模板、案例、标签：

- 放入资源与内容。
- 同步权限策略和审计。

新增账号、配额、审批、角色：

- 放入组织与治理。
- 同步审计和用量。

新增告警、发布、同步、运维参数：

- 放入系统与发布。
- 同步告警中心和审计。
