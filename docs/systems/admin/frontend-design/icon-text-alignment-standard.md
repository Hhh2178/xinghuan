# Admin Icon Text Alignment Standard

## Buttons

- Icons and text must share the same visual center.
- Icon size, gap, and line-height must be consistent for primary, secondary, ghost, and danger buttons.
- Icon-only buttons require an accessible label and a tooltip when the meaning is not obvious.

## Navigation

- Navigation icons use one size and one active-state rule.
- Active navigation should not shift item height or icon position.

## Tables And Cards

- Inline status icons must align with the text baseline and not shift row height unexpectedly.
- KPI card icons should support the value hierarchy instead of competing with it.

## Forms

- Prefix and suffix icons inside inputs must align with input text.
- Error and helper icons must not change label or field baseline alignment.
