# 视觉风格与 stitch 基线

## 1. 结论

`stitch` 设计方案可以作为 Admin 后台新版 UI 的视觉基底，但不能作为完整后台设计直接落地。

可以保留：

- 深色科技控制台风格。
- 青色主强调色。
- 小圆角、细边框、数据密集布局。
- 左侧导航 + 顶部状态栏。
- KPI 卡片。
- 右侧 Inspector 详情面板。
- 资源预览黑底 `contain` 逻辑。
- 系统健康拓扑图。
- 任务列表 + 右侧任务详情日志。
- 环境同步左右对比感。

必须调整：

- 信息架构改为五大工作域。
- 品牌统一为“星幻无限画布”。
- 补齐完整后台页面。
- 公共资源改成真正的卡片网格。
- 权限治理改成按组的权限矩阵。
- 环境同步补齐差异表、冲突决策、勾选同步和结果反馈。
- AI 助手配置拆成创作侧、后台侧、外部接入和上下文权限。
- 全局常驻的“部署新节点”按钮移除，不作为普通全局主操作。

## 2. 视觉关键词

- 专业生产工具。
- 运营驾驶舱。
- 科技黑。
- 电磁青强调。
- 高信息密度。
- 精密感。
- 数据可视化。
- 参数控制台。

## 3. 色彩方向

基础方向：

- 页面背景使用深色。
- 容器使用略亮的深灰 / 深锌色。
- 主强调使用青色。
- 成功、警告、危险必须使用语义色，不能和选中态混淆。

状态色职责：

- 主强调色：当前选中、主按钮、关键数据高亮。
- 成功色：健康、连接正常、保存成功、任务成功。
- 警告色：排队、配置缺失、性能下降、冲突待处理。
- 危险色：失败、断开、删除、禁用、不可逆操作。

禁止：

- 选中态、允许态、成功态全都使用同一种高亮色。
- 用大面积发光装饰抢占数据主视觉。
- 用低对比文字表达关键状态。

## 4. 字体和信息层级

建议：

- 中文和普通 UI：Inter / PingFang SC / Microsoft YaHei。
- 数字、ID、日志、代码：JetBrains Mono 或等宽字体。

层级：

- 页面标题：用于页面身份，不要过大。
- 区块标题：用于面板分区。
- 数据数字：允许更强视觉重量。
- 描述文本：降低权重，但必须可读。
- ID / requestId / catalogId / runTargetId：使用等宽字体，支持复制。

## 5. 组件基线

### 左侧导航

- 一级工作域固定为：
  - 运营总览
  - 能力配置
  - 资源与内容
  - 组织与治理
  - 系统与发布
- 支持折叠。
- 选中态清晰，但不应比主内容更抢眼。
- 不放全局高风险按钮。

### 顶部状态栏

展示：

- 当前环境。
- 当前版本。
- API 状态。
- 全局搜索。
- 告警入口。
- AI 助手入口。
- 当前管理员。

要求：

- 窄宽度下自动收纳次要信息。
- 环境和版本始终可见。

### KPI 卡

展示：

- 标题。
- 数值。
- 单位或说明。
- 趋势。
- 状态。
- 下钻入口。

要求：

- 指标必须能点击进入对应列表或详情。
- 不做纯装饰数字。

### Inspector

用途：

- 当前对象详情。
- 关联对象。
- 最近审计。
- 用量摘要。
- 权限摘要。
- 快捷操作。

要求：

- 右侧固定或抽屉。
- 内容过长时 Inspector 内部滚动。
- 不挤压主工作区到不可用。

### 表格

要求：

- 适合大量数据。
- 长字段省略，支持复制或完整查看。
- 行点击进入 Inspector。
- 操作列固定或明确。

### 资源卡片

要求：

- 桌面一行优先 4 个卡片。
- 上半区为黑底完整预览。
- 图片、视频、音频都不能裁切主体。
- 下半区为标题、分类、标签、备注、文件信息和操作。
- 操作按钮可换行，不溢出。

落地约定：

- 页面级使用 `admin-public-resources-page--starlight` 标识，资源卡片使用 `admin-public-resource-card--starlight` 标识。
- 卡片预览舞台使用 `admin-public-resource-card__preview-stage`，内部媒体统一 `object-fit: contain`。
- 完整预览弹窗使用 `admin-media-preview-modal--starlight`，弹窗媒体同样必须完整展示。
- 操作按钮放入 `admin-public-resource-card__action-row`，所有 action row 默认 `flex-wrap: wrap`。
- 分类名称使用 `admin-public-resources-category-card__name`，文字颜色保持白色，长名称允许安全换行。

## 6. stitch 方案保留与修正清单

保留为设计资产：

- 总览页 KPI 和趋势布局。
- Provider 页左列表 + 中表单 + 右 Inspector。
- 系统健康拓扑图。
- 任务页 KPI + 队列深度 + 任务详情日志。
- 环境同步的左右环境对比。
- 深色细边框控制台语言。

必须重画：

- 左侧导航。
- 公共资源卡片网格。
- 账号 / 用户组 / 权限策略矩阵。
- 模型目录。
- RH AI 应用。
- RH 工作流。
- RH Key 池。
- 用量分析。
- 审计日志。
- 运行参数。
- 发布状态。

## 7. 设计红线

不允许：

- 文字溢出容器。
- 按钮挤压到不可读。
- 表格撑爆页面。
- 卡片因为动态内容高度失控。
- 资源预览裁切主体。
- 分类或分组只能在很小区域滚动。
- 无意义双滚动条。
- 删除、发布、同步等高风险操作没有确认。
- 无权限内容在前台显示拒绝状态。
