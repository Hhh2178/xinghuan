# development - 开发过程资料

本目录用于保存开发过程中的方案草稿、POC 记录、临时实现说明和迁移评估。

当前结构约定：

- 根目录：仍在参考或后续可能继续推进的过程文档
- `logs/`：仅保留仍需要人工回看的本地运行日志；过期调试日志应及时单文件清理
- `_archive/`：不再继续推进、但需要保留上下文的过程资料归档区

当前保留的根目录文档都仍有明确用途，不再额外散落新的临时快照或打包副本。

整理规则：

- 已经沉淀为正式产品/技术规则的内容，优先收口到 `docs/`
- 已经变成运维或部署证据的内容，优先收口到 `ops/`
- 失去当前推进价值但仍需要保留来龙去脉的内容，移入 `_archive/`

- `milestone-b-baseline.md`：Milestone B 工程基线记录
